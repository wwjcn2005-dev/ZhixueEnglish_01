## 1. 继承关系与优先级

优先级（从高到低）：

1. 《初中英语 AI 辅助学习系统最高指导原则与开发规范》——"教材是主线，学习是核心，孩子做主，AI 做助手"。

| Unit | **8 个**：Starter、Unit 1–6、Appendix | 可成为正式页面 |
| Section（46）/ Activity（96） | 存在，但 **Activity → 学习资源结构化关联 = 0/362** | **不作为第一版独立页面**，仅作"教材出处"文字 |
| Vocabulary | 287 条，其中可学（CORE）**243** | 第一优先，完整 Study → Recall → Practice → Result |
| Phrase | 23 条，其中可学（CORE）**2**，且二者均无中文释义 → Recall 不可用 | 第一版仅 Study |
| Sentence Pattern | 52 条，其中可学（CORE）**1** | 第一版仅 Study |
| 音标 / 词性 / 释义 | 部分存在（有则显示，无则整行不显示） | 不显示"暂无/未知/N/A" |
| 教材出处 | 来源栏目 + 印刷页可解析 | 以"栏目 · 第 N 页"呈现 |

| 词汇 → Unit 归属 | **当前数据不足**（287 词均挂在词表页；242/243 仅可由词条尾部印刷页号推断，非结构化字段） | Unit 页面不得虚构"本单元单词"数量 |

## 3. 全局手机布局约定（页面通用）

不进入 Android 技术实现，只规定版面结构：

| 区域 | 约定 |
| --- | --- |
| 顶部区域 | 左：返回（除首页/启动页外必有）；中：页面标题（不抢内容焦点）；右：默认留空。高度固定，始终可见，不随内容滚动。 |
| 内容区域 | 单列，左右边距约 20dp；以卡片/列表组织；卡片不嵌套超过一层；内容优先，留白优先。 |
| 按钮区域 | 主操作固定在内容流末尾（不悬浮、不遮挡内容）；次操作与文字按钮置于主操作下方或右上角。 |
| 底部留白 | 内容结束后保留约 24dp 空白，避免主按钮贴屏幕底缘。 |
| 滚动方式 | 内容超过一屏时整页纵向滚动；顶部区域固定；不横滑、不做轮播。 |
| 长内容处理 | 长列表（词汇表/资源列表）按字母或单元分组，允许滚动加载；单条过长时省略号截断，不改变卡片高度。 |
| 小屏幕处理 | 以"一屏一个焦点"为原则：小屏只保证"第一视觉中心 + 主操作"完整可见，其余信息自然折行或下移。 |

## 4. 页面级视觉优先级（通则）

每个页面必须明确：**第一视觉中心 → 第二视觉信息 → 第三视觉信息 → 主要操作 → 次要操作**。任何页面都不得让"页面标题/装饰/统计"压过第一视觉中心。

三条硬性规则：

- **Vocabulary Study**：单词 > 释义 > 教材信息 > 操作。
- **Vocabulary Recall**：单词 > 记忆判断 > 辅助操作。
- **Result**：学习内容 > 孩子自己的判断 > 下一步选择。

## 5. 页面状态统一定义

| 状态 | 统一定义 |
| --- | --- |
| Loading | 数据未就绪时的等待表现：文字提示（如"正在打开…"）+ 轻量指示；禁止整屏动画、禁止超过 3 秒无反馈 |
| Empty | 该页确实没有内容时的说明；用自然语言陈述事实，禁止出现"恭喜/完美/已全部掌握"等奖励或断言 |
| Error | 操作或数据失败时的自然语言说明 + 可执行动作（重试/返回）；禁止暴露 HTTP 状态码、Exception、SQL、trace、堆栈 |
| Success | 操作成功时仅做轻量确认（文字/轻微反馈）；不使用奖励动画与音效 |
| Back | 系统返回键与页面左上角返回**行为必须一致**，目标为"进入该页时的上一级" |
| 重复点击 | 同一提交类按钮连续点击**只产生一次结果**（沿用既有服务保护）；页面保持上次结果，不报错、不重复写入 |
| 学习中离开 | 允许随时离开；未提交的判断不产生记录；已提交的判断保持已写入事实，不提示"未完成"、不催促继续 |

## 6. 首页必须回答的三个问题

1. **我现在可以学什么？**
2. **有没有需要再学的？**
3. **我想从教材哪里开始？**

首页不是数据仪表盘。禁止出现：正确率、掌握率、雷达图、排名、积分、连续天数、徽章、游戏化统计。

## 7. 页面设计（11 个正式页面）

以下每页严格按统一模板（20 项）设计；不适用项必须写明原因，禁止留空。

### 01 启动页

1. **页面名称**：启动页
2. **页面目的**：确认应用可用、确认本机是否已有使用者，决定进入"首次使用"还是"首页"。
3. **用户进入方式**：点击应用图标（唯一入口）。
4. **页面退出方式**：自动离开（启动流程内），或数据不可用时停留在错误态等待重试。
5. **页面视觉层级**：第一＝应用名称/标识；第二＝加载提示；第三＝版本信息（极辅助，可选）。
6. **页面布局结构**：顶部区不适用（启动页无返回）；内容区居中；按钮区仅错误态出现；底部留空。
7. **页面主要内容**：应用名 + 极简加载指示；错误时显示自然语言提示与"重试"。
8. **数据来源**：本地是否存在使用者信息；数据可用性检查（learning.db 与教材数据可读）。
9. **主操作**：无（自动进入下一步）。
10. **次操作**：错误态"重试"。
11. **所有按钮及去向**：`重试` → 重新检查并继续启动流程（仅错误态出现）。
12. **页面返回行为**：不适用，原因：启动页是流程入口，无上一级。
13. **Loading 状态**：应用名 + "正在打开…"。
14. **Empty 状态**：不适用，原因：启动页不呈现内容集合。
15. **Error 状态**："应用暂时打不开，请稍后再试。" + `重试`；不得显示技术信息。
16. **重复点击行为**：不适用，原因：本页无提交类按钮。
17. **离开页面行为**：不适用，原因：本页为流程起点，退出应用即离开。
18. **不允许出现的内容**：技术日志、数据库/文件路径、内部枚举、AI 装饰、广告、更新公告弹窗。
19. **与其他页面的关系**：启动页 →（无使用者）首次使用；→（已有使用者）首页。
20. **页面完成后的下一步选择**：无（自动进入，属启动流程，不属于学习内容自动跳转）。

### 02 首次使用

1. **页面名称**：首次使用（请输入名字）
2. **页面目的**：建立一个本机可识别的使用者，使学习记录有归属。
3. **用户进入方式**：启动页在"本机没有使用者"时自动进入。
4. **页面退出方式**：提交名字后进入首页；返回键退出应用（不产生记录）。
5. **页面视觉层级**：第一＝"请输入你的名字"；第二＝输入框；第三＝说明文字（这句话只用于区分本机的学习记录）。
6. **页面布局结构**：顶部区（无返回）；内容区居中单列；按钮区在主操作位；底部留空。
7. **页面主要内容**：一句说明 + 一个名字输入框 + 主按钮。
8. **数据来源**：本机使用者信息（`learner.display_name`）。
9. **主操作**：`开始使用`。
10. **次操作**：无（不做"跳过"，原因：学习记录必须有归属）。
11. **所有按钮及去向**：`开始使用` → 首页（名字为空时原地提示，不跳转）。
12. **页面返回行为**：系统返回 = 退出应用（不适用页面级返回，原因：本页是最外层输入页）。
13. **Loading 状态**：提交后轻量等待（"正在准备…"）。
14. **Empty 状态**：不适用，原因：本页是输入页，无内容集合。
15. **Error 状态**："名字没有保存成功，请再试一次。"（不得显示技术信息）。
16. **重复点击行为**：只创建一次使用者；连续点击不产生第二个使用者。
17. **离开页面行为**：未提交即离开 → 不产生任何记录；下次进入仍为首次使用。
18. **不允许出现的内容**：账号、密码、手机号、验证码、头像上传、云同步、隐私授权清单、内部枚举。
19. **与其他页面的关系**：启动页 → 首次使用 → 首页（之后默认记住，不再要求输入）。
20. **页面完成后的下一步选择**：进入首页（唯一去向）。

### 03 首页

1. **页面名称**：首页（学习导航大厅）
2. **页面目的**：回答"我现在可以学什么 / 有没有需要再学的 / 我想从教材哪里开始"。
3. **用户进入方式**：启动流程完成；或从任意页面通过"回到首页"。
4. **页面退出方式**：进入教材中心 / 需要再学 / 资源列表；无自动跳转。
5. **页面视觉层级**：第一＝"我的教材"卡片（教材是主线）；第二＝"需要再学"；第三＝"教材学习入口"与"最近学过"。
6. **页面布局结构**：顶部区（标题"首页"，无返回）；内容区四块依次纵向排列；按钮区随各卡片；底部留白。
7. **页面主要内容**：① 我的教材（书名、出版社、年级册次 + `进入教材中心`）；② 需要再学（`上次忘了 N 个`、`上次有点模糊 M 个` + `去看看`）；③ 教材学习入口（`按单元学`、`词汇表`、`短语`、`句型`）；④ 最近学过（第一版不显示，原因：当前数据不足）。
8. **数据来源**：① `textbook_edition`；② 只读池服务（当前错误 → 上次忘了，当前薄弱 → 上次有点模糊）；③ contentpack 真实资源；④ 【当前数据不足】缺只读的"最近学习"查询。
9. **主操作**：`进入教材中心`（教材是主线）。
10. **次操作**：`去看看`（需要再学）；`词汇表 / 短语 / 句型`。
11. **所有按钮及去向**：`进入教材中心` → 教材中心；`去看看` → 需要再学；`按单元学` → 教材中心（Unit 列表）；`词汇表` → 资源列表（词汇）；`短语` → 资源列表（短语）；`句型` → 资源列表（句型）。
12. **页面返回行为**：首页无返回（最外层）；从其他页面返回首页时回到本页顶部。
13. **Loading 状态**：卡片骨架/文字"正在准备…"（分块加载，不整屏阻塞）。
14. **Empty 状态**：需要再学为空时显示"暂时没有需要再学的内容"；其余卡片始终有内容（教材固定存在）。
15. **Error 状态**：分块降级——某块失败只在该块内提示"这块内容暂时加载不出来"，其余块可用。
16. **重复点击行为**：导航类按钮重复点击不产生额外副作用；不重复发起写入（本页不写入）。
17. **离开页面行为**：本页不产生任何学习记录；离开不提示。
18. **不允许出现的内容**：正确率、掌握率、雷达图、排名、积分、连续天数、徽章、任务清单、"系统推荐/最应该学"、内部枚举与字段、AI 对话入口。
19. **与其他页面的关系**：首页是唯一枢纽；教材中心与需要再学是两条主路径起点。
20. **页面完成后的下一步选择**：孩子自选：教材中心 / 需要再学 / 直接进入某类资源。

### 04 教材中心

1. **页面名称**：教材中心
2. **页面目的**：让孩子明确"我现在用的是哪一本教材"，并从教材进入学习。
3. **用户进入方式**：首页 `进入教材中心`（或 `按单元学`）。
4. **页面退出方式**：返回首页；或进入 Unit 页面 / 资源列表。
5. **页面视觉层级**：第一＝教材信息卡；第二＝Unit 列表；第三＝资源类型入口。
6. **页面布局结构**：顶部区（返回 + "教材中心"）；内容区（教材卡 → Unit 列表 → 资源入口）；按钮区随卡片；底部留白。
7. **页面主要内容**：教材卡（外研社《义务教育教科书·英语 七年级上册》·2022 课程标准修订）；Unit 列表（Starter、Unit 1–6、Appendix，共 8 项，含单元名与页码）；资源入口（`词汇表`、`短语`、`句型`）。
8. **数据来源**：`textbook_edition`（书名/出版社/年级册次/课标）与 `unit`（unit_code / title / 印刷页范围）；资源入口来自 `learning_item.item_type`。
9. **主操作**：进入某个 Unit。
10. **次操作**：进入词汇表 / 短语 / 句型；返回首页。
11. **所有按钮及去向**：每个 Unit 行 → Unit 页面；`词汇表` → 资源列表（词汇）；`短语` → 资源列表（短语）；`句型` → 资源列表（句型）；`返回` → 首页。
12. **页面返回行为**：返回 = 首页（进入来源为首页时）。
13. **Loading 状态**：文字"正在打开教材…"。
14. **Empty 状态**：不适用，原因：教材与 8 个 Unit 为固定真实数据，必然存在。
15. **Error 状态**："教材内容暂时打不开，请稍后再试。" + `重试`。
16. **重复点击行为**：同一 Unit 连续点击只进入一次；不产生重复会话（进入学习由后续页面创建）。
17. **离开页面行为**：本页不产生学习记录。
18. **不允许出现的内容**：Section 列表、Activity 列表、教材解析字段（页码区间以外的技术信息）、内部枚举、封面大图装饰。
19. **与其他页面的关系**：首页 ↔ 教材中心 ↔ Unit 页面 / 资源列表。
20. **页面完成后的下一步选择**：选一个 Unit，或直接进入某类资源列表。

### 05 Unit 页面

1. **页面名称**：Unit 页面
2. **页面目的**：呈现一个单元的身份与可学内容，作为"按教材学习"的入口。
3. **用户进入方式**：教材中心的 Unit 列表（8 项之一）。
4. **页面退出方式**：返回教材中心；或进入资源列表 / 资源学习。
5. **页面视觉层级**：第一＝Unit 名称与编号；第二＝本单元可学内容；第三＝教材页码等辅助信息。
6. **页面布局结构**：顶部区（返回 + "Unit"）；内容区（单元标题卡 → 可学内容列表）；按钮区随列表；底部留白。
7. **页面主要内容**：Unit 名称（如 `Unit 1 A new start`）与页码；本单元可学内容：**句型（真实可算）**；`词汇` 入口（说明"按全书词汇表查看"）。
8. **数据来源**：`unit`（name/title/页码）；句型数量由 `source_ref → content_block → page` 归属动态计算（当前真实：Unit 1 = 6、Unit 2 = 4、Unit 3 = 4、Unit 4 = 6、Unit 5 = 6、Unit 6 = 8；Starter 与 Appendix 不适用）；**词汇 → 单元归属【当前数据不足】**（词条仅在书末词表页，需先补齐结构化归属，第一版不显示"本单元单词 N 个"）。
9. **主操作**：进入本单元可学内容（句型 / 词汇表）。
10. **次操作**：返回教材中心。
11. **所有按钮及去向**：`本单元句型` → 资源列表（句型，按本单元过滤）；`词汇` → 资源列表（词汇表，含说明文字）；`返回` → 教材中心。
12. **页面返回行为**：返回 = 教材中心。
13. **Loading 状态**：文字"正在打开这个单元…"。
14. **Empty 状态**：本单元没有可学内容时显示"这个单元暂时没有可以直接学习的内容"（不显示 0 数字、不显示空卡片）。
15. **Error 状态**："这个单元暂时打不开，请稍后再试。"
16. **重复点击行为**：同上，导航类按钮只生效一次。
17. **离开页面行为**：本页不产生学习记录。
18. **不允许出现的内容**：Section/Activity 层级、学习目标占位文本（当前真实目标内容不可用）、内部枚举、虚构的"本单元单词数量"。
19. **与其他页面的关系**：教材中心 → Unit 页面 → 资源列表 → 学习流程。
20. **页面完成后的下一步选择**：进入本单元句型列表，或进入词汇表。

### 06 资源列表

1. **页面名称**：资源列表（词汇表 / 短语 / 句型）
2. **页面目的**：让孩子浏览并自己选择要学的资源（不需要背诵拼写才能进入）。
3. **用户进入方式**：首页资源入口、教材中心资源入口、Unit 页面、需要再学列表的"全部"入口。
4. **页面退出方式**：返回上一级；或进入某条资源的学习。
5. **页面视觉层级**：第一＝资源列表（条目文本）；第二＝条目附属信息（音标/词性/释义/教材出处）；第三＝列表说明与筛选。
6. **页面布局结构**：顶部区（返回 + 标题 + 可选分组切换）；内容区为分组列表（词汇表按字母分组）；按钮区无（列表即入口）；底部留白。
7. **页面主要内容**：三类模式——① 词汇表（单词 + 音标/词性/释义，有则显示；可按字母分组，或按教材单元入口进入）；② 短语（短语 + 释义，有则显示）；③ 句型（句型框架）。条目上可显示学习状态提示（如"上次忘了"）。
8. **数据来源**：`learning_item`（canonical_text / phonetic / part_of_speech / meaning_zh）与 `source_ref`（教材出处）；学习状态来自只读池服务。
9. **主操作**：选择一条资源进入学习。
10. **次操作**：切换分组 / 筛选"只看需要再学的"（第二阶段）/ 返回。
11. **所有按钮及去向**：条目 → 该资源的学习页（词汇 → Study；短语/句型 → Study）；`返回` → 上一级；`只看需要再学的` → 需要再学（第二阶段）。
12. **页面返回行为**：返回 = 进入来源页（首页 / 教材中心 / Unit 页面）。
13. **Loading 状态**：文字"正在打开列表…"；长列表分页/分段加载时保持已有内容可见。
14. **Empty 状态**："这里还没有可以学习的内容。"（不使用庆祝式文案；不显示内部空值）。
15. **Error 状态**："内容暂时加载不出来，请稍后再试。" + `重试`。
16. **重复点击行为**：连续点击同一条目只进入一次学习（不产生重复会话/重复记录）。
17. **离开页面行为**：浏览不产生任何记录；离开不提示。
18. **不允许出现的内容**：`CORE / RECOGNITION / NEED_REVIEW`、`current_error / current_weak`、`item_id`、`contentpack`、数据库字段名、数量统计仪表盘。
19. **与其他页面的关系**：首页 / 教材中心 / Unit 页面 / 需要再学 → 资源列表 → 学习流程。
20. **页面完成后的下一步选择**：继续浏览并再选一条，或进入所选资源学习，或返回上一级。

### 07 Vocabulary Study

1. **页面名称**：Vocabulary Study（学习页面）
2. **页面目的**：让孩子完整看清这个单词的教材信息，然后表示"我看完了"。
3. **用户进入方式**：资源列表（词汇）、需要再学列表、Unit 页面入口、Result 页"再学一次"。
4. **页面退出方式**：返回上一级（不产生记录）；或 `我看完了` 进入 Recall。
5. **页面视觉层级**：**单词 > 释义 > 教材信息 > 操作**（单词为第一视觉中心，字号 36–44sp）。
6. **页面布局结构**：顶部区（返回 + 极简标题）；内容区（单词 → 音标 → 词性 → 中文释义 → 教材出处）；按钮区（主操作固定于内容末尾）；底部留白。
7. **页面主要内容**：单词（canonical_text）；音标（有则显示）；词性（有则显示）；中文释义（有则显示）；教材出处（如"词汇表 · 第 152 页"）。
8. **数据来源**：`learning_item`（canonical_text / phonetic / part_of_speech / meaning_zh）；出处来自 `source_ref`（栏目 + 印刷页）。
9. **主操作**：`我看完了` → 进入 Recall。
10. **次操作**：返回上一级；`换一个词`（回资源列表）。
11. **所有按钮及去向**：`我看完了` → Vocabulary Recall；`换一个词` → 资源列表（词汇）；`返回` → 上一级。
12. **页面返回行为**：返回 = 上一级（资源列表 / 需要再学 / Unit 页面 / Result）。
13. **Loading 状态**：文字"正在打开这个词…"（内容未就绪时不显示半截信息）。
14. **Empty 状态**：不适用，原因：本页只呈现一条真实存在的资源；若资源缺失则转入 Error。
15. **Error 状态**："这个词暂时打不开，请稍后再试。" / "找不到这个词了。" + `重试` 或 `返回`。
16. **重复点击行为**：连续点击 `我看完了` 只产生一条"看过"记录，进入一次 Recall。
17. **离开页面行为**：未点 `我看完了` 就离开 → 不产生记录；离开不提示、不阻止。
18. **不允许出现的内容**：`item_id`、`task_id`、`session_id`、`CORE`、`contentpack`、`study`、`done`、掌握度、正确率、内部技术状态、AI 气泡、自动进入下一个词。
19. **与其他页面的关系**：资源列表 → Study → Recall → Practice → Result。
20. **页面完成后的下一步选择**：进入 Recall（唯一前向动作），或返回上一级离开。

### 08 Vocabulary Recall

1. **页面名称**：Vocabulary Recall（回忆页面）
2. **页面目的**：让孩子先自己回忆，再对自己此刻的记忆状态作出判断。
3. **用户进入方式**：Vocabulary Study 的 `我看完了`。
4. **页面退出方式**：返回 Study；或点击三个判断之一进入 Practice。
5. **页面视觉层级**：**单词 > 记忆判断 > 辅助操作**。
6. **页面布局结构**：顶部区（返回 + 极简标题）；内容区（单词 + 音标/词性 + 释义区 + `显示意思`）；按钮区（三个等权判断按钮横向或纵向等宽排列）；底部留白。
7. **页面主要内容**：单词；音标/词性（有则显示）；中文释义**默认隐藏**；`显示意思`；三个等权选择：**`我记得` / `有点模糊` / `忘了`**。
8. **数据来源**：`learning_item`（同 Study）；判断结果最终以既有学习记录语义（内部 `correct / partial / incorrect`）写入，**孩子界面只显示"我记得/有点模糊/忘了"**。
9. **主操作**：三个判断按钮之一（视觉等权，无主次之分）。
10. **次操作**：`显示意思`（辅助核对，不产生记录）。
11. **所有按钮及去向**：`显示意思` → 本页内显示释义（不跳转、不记录）；`我记得` / `有点模糊` / `忘了` → Practice（记录确认页）。
12. **页面返回行为**：返回 = Study（可再看一遍单词）。
13. **Loading 状态**：文字"正在准备回忆…"（进入本页时极短）。
14. **Empty 状态**：不适用，原因：本页内容来自一条已选定的资源。
15. **Error 状态**："刚才这一步没有成功，请再试一次。"
16. **重复点击行为**：同一判断按钮连续点击只提交一次；提交后按钮进入不可重复提交状态，页面保持结果。
17. **离开页面行为**：未作判断就离开 → **不产生任何记录**；已提交后离开 → 记录保持，不提示未完成。
18. **不允许出现的内容**：红/绿对错色暗示、倒计时、进度条、"答对/答错/系统判定/部分正确"、任何评分或评价语言、内部枚举、自动在若干秒后判定。
19. **与其他页面的关系**：Study → Recall → Practice → Result。
20. **页面完成后的下一步选择**：作出三个判断之一（进入 Practice），或返回 Study / 离开。

### 09 Vocabulary Practice

1. **页面名称**：Vocabulary Practice（判断确认页）
2. **页面目的**：完成孩子自己的学习判断并确认它已被记录——**这不是考试页**。
3. **用户进入方式**：Vocabulary Recall 中点击 `我记得` / `有点模糊` / `忘了`。
4. **页面退出方式**：`看看结果` 进入 Result；或返回 Recall。
5. **页面视觉层级**：第一＝孩子刚才的选择（自然语言）；第二＝这次学习的一句话说明；第三＝下一步按钮。
6. **页面布局结构**：顶部区（返回 + 极简标题）；内容区（单词 + "你选择的是：…"+ 一句说明）；按钮区（主操作 `看看结果`）；底部留白。
7. **页面主要内容**：单词；孩子刚才的选择（`我记得` / `有点模糊` / `忘了`）；一句中性说明（如"刚刚的回忆已经记下来了"；若选"忘了/有点模糊"，仅陈述"这个词会出现在『需要再学』里"，**不表达失败**）。
8. **数据来源**：本页对应的判断在进入时由既有学习服务写入一条真实学习记录；页面只读取该次结果，不展示内部字段。
9. **主操作**：`看看结果`。
10. **次操作**：`返回`（回到 Recall 再看一次，不会重复写入记录）。
11. **所有按钮及去向**：`看看结果` → Result；`返回` → Recall（只读回看，不重复提交）。
12. **页面返回行为**：返回 = Recall。
13. **Loading 状态**：文字"正在记录…"（极短，避免"系统正在评分"的错觉）。
14. **Empty 状态**：不适用，原因：本页必然对应一次已作出的选择。
15. **Error 状态**："刚才的记录没有成功，请再选一次。" → 回到 Recall 重新选择。
16. **重复点击行为**：`看看结果` 连续点击只进入一次 Result；本页**不会**重复写入第二条记录。
17. **离开页面行为**：记录已写入即保留；离开不提示、不催促。
18. **不允许出现的内容**：`correct / incorrect / partial`、`答对 / 答错 / 正确 / 错误 / 系统判定 / 部分正确`、正确率、分数、评级、失败提示、"再练一次否则…"之类压力语言。
19. **与其他页面的关系**：Recall → Practice → Result；Practice 是"判断确认"，不是第二套学习流程。
20. **页面完成后的下一步选择**：`看看结果`（进入 Result），或返回 Recall 再看一次。

### 10 Result

1. **页面名称**：Result（结果页）
2. **页面目的**：回答"刚刚学了什么 / 孩子自己怎么判断 / 接下来可以做什么"。
3. **用户进入方式**：Practice 的 `看看结果`；短语/句型 Study 的"我看完了"（无回忆环节时直接进入）。
4. **页面退出方式**：三个并列按钮之一；无自动跳转。
5. **页面视觉层级**：**学习内容 > 孩子自己的判断 > 下一步选择**。
6. **页面布局结构**：顶部区（返回 + 极简标题）；内容区（资源文本 + 释义 + 教材出处 + 判断结论）；按钮区（三个并列按钮）；底部留白。
7. **页面主要内容**：刚学的资源（单词/短语/句型）；中文释义与教材出处；"你的回忆状态：我记得 / 有点模糊 / 忘了"（仅陈述孩子自己的选择）；三个下一步按钮。
8. **数据来源**：`learning_item` 与 `source_ref`；本次判断来自刚写入的 `learning_record`；"学过几次"可来自 `mastery_state.evidence_count`（**只显示次数，不显示等级/百分比**）。
9. **主操作**：`再学一次`。
10. **次操作**：`回到词汇表`；`看看需要再学的`。
11. **所有按钮及去向**：`再学一次` → 同一资源的 Study（新建一次学习）；`回到词汇表` → 资源列表（进入来源为词汇表时）；`看看需要再学的` → 需要再学；`返回` → 上一个学习页（只读回看）。
12. **页面返回行为**：返回 = 进入学习时的来源页（资源列表 / 需要再学 / Unit 页面）。
13. **Loading 状态**：文字"正在整理这次学习…"（极短）。
14. **Empty 状态**：不适用，原因：本页必然对应一次已完成的学习。
15. **Error 状态**："这次的结果暂时显示不出来。" + `返回`。
16. **重复点击行为**：`再学一次` 每次点击进入一个新的学习流程（孩子主动选择，允许）；其余按钮只导航。
17. **离开页面行为**：离开不产生新记录；不提示。
18. **不允许出现的内容**：分数、排名、正确率、掌握率、"你已掌握"、答对/答错、系统评价、奖励动画、自动跳转、自动进入下一个资源。
19. **与其他页面的关系**：Study → Recall → Practice → Result →（孩子自选）资源列表 / 需要再学 / 再学一次。
20. **页面完成后的下一步选择**：`再学一次` / `回到词汇表` / `看看需要再学的` / 直接离开。

### 11 需要再学

1. **页面名称**：需要再学
2. **页面目的**：让孩子看到"现在有哪些内容需要我再学"，并由自己选择是否再学。
3. **用户进入方式**：首页"需要再学"卡片；Result 的 `看看需要再学的`；（第二阶段）资源列表的筛选入口。
4. **页面退出方式**：返回首页或上一级；或点某条资源进入学习。
5. **页面视觉层级**：第一＝资源本身（单词/短语/句型）；第二＝需要再学的原因（上次忘了 / 上次有点模糊）；第三＝数量与说明。
6. **页面布局结构**：顶部区（返回 + "需要再学"）；内容区（"上次忘了"分组 → "上次有点模糊"分组，组内列表）；按钮区随条目（`再学这个词`）；底部留白。
7. **页面主要内容**：两个分组：**"上次忘了"** 与 **"上次有点模糊"**；每条显示资源文本 + 音标/词性/释义（有则显示）+ `再学这个词`；顶部可显示两类数量。
8. **数据来源**：只读池服务（当前错误 → 上次忘了；当前薄弱 → 上次有点模糊）；条目文本与释义来自 `learning_item`；**数量为动态计算**。
9. **主操作**：点某条资源的 `再学这个词`。
10. **次操作**：返回；切换分组（若列表较长）。
11. **所有按钮及去向**：`再学这个词` → 该资源的 Study（进入既有学习链，**不需要孩子重新输入**）；`返回` → 上一级。
12. **页面返回行为**：返回 = 进入来源页（首页 / Result / 资源列表）。
13. **Loading 状态**：文字"正在看看有什么需要再学…"。
14. **Empty 状态**："暂时没有需要再学的内容。" + 一句中性说明（"这里只显示上次为『忘了』或『有点模糊』的内容"）；禁止"恭喜/完美/已全部掌握"。
15. **Error 状态**："刚才没有找到需要再学的内容，请稍后再试。" + `重试`。
16. **重复点击行为**：同一条资源连续点击只进入一次学习；本页不产生任何写入。
17. **离开页面行为**：浏览与返回都不改变池状态；只有真正完成一次判断才由既有服务更新。
18. **不允许出现的内容**：`当前错误池 / 当前薄弱池 / 错误资源池 / 弱项资源池`、错误数量统计、正确率、掌握率、排行榜、内部枚举、自动开始学习、自动连续复习。
19. **与其他页面的关系**：首页 / Result ↔ 需要再学 ↔ 既有学习链（Study → Recall → Practice → Result）。
20. **页面完成后的下一步选择**：再学一条，或返回首页/上一级离开。

## 8. 页面间导航矩阵

第一版导航采用：**首页 + 页面返回**（不使用底部导航）。

- 系统返回键与页面左上角返回**行为一致**，目标为进入该页时的上一级。
- **结果页不自动跳转**；所有学习流程结束后，下一步一律由孩子选择。
- 学习主路线：`首页 → 教材中心 → Unit → 资源列表 → 资源学习 → Result → 孩子再次选择`。
- 第二条入口：`首页 → 需要再学 → 上次忘了 / 上次有点模糊 → 选择具体资源 → 进入已有学习链`。

| 当前页面 | 触发操作 | 目标页面 | 是否自动 | 备注 |
| --- | --- | --- | --- | --- |
| 启动页 | 启动完成（有使用者） | 首页 | **是** | 属启动流程，非学习内容跳转 |
| 启动页 | 启动完成（无使用者） | 首次使用 | **是** | 属启动流程 |
| 启动页 | 数据不可用 | 启动页（错误态） | 否 | 需孩子/家长点 `重试` |
| 首次使用 | `开始使用` | 首页 | 否 | 需用户提交 |
| 首页 | `进入教材中心` / `按单元学` | 教材中心 | 否 | 手动 |
| 首页 | `去看看` | 需要再学 | 否 | 手动 |
| 首页 | `词汇表` / `短语` / `句型` | 资源列表 | 否 | 手动 |
| 教材中心 | 点击某个 Unit | Unit 页面 | 否 | 手动 |
| 教材中心 | `词汇表` / `短语` / `句型` | 资源列表 | 否 | 手动 |
| Unit 页面 | `本单元句型` / `词汇` | 资源列表 | 否 | 手动 |
| 资源列表 | 点击某条资源 | 该资源 Study | 否 | 手动 |
| 需要再学 | `再学这个词` | 该资源 Study | 否 | 进入既有学习链，不需重新输入 |
| Study | `我看完了` | Recall（词汇）/ Result（短语、句型） | 否 | 手动 |
| Recall | `显示意思` | 本页（显示释义） | 否 | 不产生记录 |
| Recall | `我记得` / `有点模糊` / `忘了` | Practice | 否 | 手动，产生一次记录 |
| Practice | `看看结果` | Result | 否 | 手动 |
| Practice | `返回` | Recall | 否 | 只读回看，不重复提交 |
| Result | `再学一次` | 该资源 Study | 否 | 手动 |
| Result | `回到词汇表` | 资源列表 | 否 | 手动 |
| Result | `看看需要再学的` | 需要再学 | 否 | 手动 |
| 任意非首页页面 | 系统返回 / 左上角返回 | 进入该页时的上一级 | 否 | 两者行为必须一致 |

**结论：除启动流程外，页面之间不存在任何自动跳转。**

## 9. 第一版明确不做

**这些不是遗漏，而是第一版主动不做。**
