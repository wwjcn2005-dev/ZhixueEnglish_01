## 2. V2 核心目标

最高原则不变：**教材是主线，学习是核心，孩子做主，AI 做助手。**

系统应该让孩子用最少的页面和操作进入真正的学习，并通过真实学习证据让孩子清楚知道自己学得怎么样。

## 3. 一级导航

一级页面不超过 3 个：

| 一级页面 | 回答的问题 |
| --- | --- |
| 首页 | 我现在怎么样？ |
| 学习 | 我想学什么？ |
| 进展 | 我到底学会了多少？ |

禁止把 Vocabulary / Grammar / Listening / Reading 拆成多个一级导航。它们属于学习内容类型，进入学习后作为内容组织方式出现。

## 4. 首页定义

首页不是功能大厅。

首页是 Learning Home / 学习首页，不是功能大厅、Dashboard、AI聊天页、数据驾驶舱、教材百科或任务管理器。

首页信息优先级：

```text
当前学习状态
→ AI评价
→ 下一步建议
→ 我的进展
→ 学习内容入口
```

首页示例：

```text
Unit 2 · Vocabulary

20个词
16个掌握较稳定
3个学习中
1个需要巩固

最近3次回忆中，16个词表现稳定；
environment连续两次主动回忆不稳定。

建议先复习environment。

[复习1个词]
```

禁止首页出现：

- 欢迎回来
- 今天也要加油
- 让我们开始一段精彩的学习旅程
- 无真实数据的鼓励语
- 装饰性欢迎卡片

## 5. 学习页

学习页回答：我想学什么？

### 5.1 课程页（当前唯一有效结构 · 2026-09-19 同步）

课程页（含首页）承载"当前课时 + 学习入口"，**只有六个学习入口**，顺序固定：

```text
跟读练习 → 听音辨意 → 词形练习 → 本课检测 → 自主练习 → 听读课文
```

- 入口可见性按**该功能自身的正式资源规则**判断；不同功能允许在各自明确的资源范围内跨 Section / Unit 使用。
- **正式学习功能集合 ≠ 当前入口显隐 ≠ 功能内容层资源状态（2026-09-27 同步）**：
  `read / listen / phonetic / form / check / practice` 是**正式学习功能集合**，但**主页与次页中的所有正式学习功能入口
  （不只首页六项）显示哪些，由当前所选 Section 对应功能的真实资源可用性决定**；当前 Section 没有该功能所需资源时，
  该功能入口**可以不显示**——**不为凑齐六项而显示空入口或不可用入口**；**不得**用整个 Unit 的资源总量代替当前
  Section 的真实可调用资源来判定。
- **入口不显示 ≠ 删除 Section**：不得因某功能在当前 Section 无资源就删除该 Section 或把它从完整目录 / 选择器中移除；
  完整教材目录与「当前课时」选择器仍保留 **8 组、46 个 Section**。
- **进入功能之后**（功能内容层）：若页面或内容区确实没有资源，应**如实呈现真实空状态**，不伪造内容、
  不静默替换 Section 或资源范围。**「入口不显示」与「进入后的空状态」是两层不同处理**（细则见 V1.3 第二十九章 §15）。
- 该规则**不得**将自主练习等功能限制为当前课时 / 当前 Section。
- **听音辨意**是同一条入口，`单词听辨｜句子听辨` 是其**内部模式**（同一行展示）；**「听音阅读」模式已于 2026-09-30 正式删除**（无正式资源、无保留意义）：
  **只显示当前 Section 有资源的模式**（无资源的模式不显示；不再要求三模式常显）；默认模式
  （`单词听辨`）无资源时按 `单词听辨 → 句子听辨` 改选当前 Section 内第一个有资源的模式
  （细则见 V1.3 第二十九章 §15·2 / §15·4-C）。"听音写词"已删除，不再作为独立入口、独立学习模块或后续开发目标。
- **本课检测**包含阅读能力（阅读选择 + 阅读简答），不再设独立"阅读理解"入口。
- **自主练习**覆盖孩子已经学过的全部内容（以已经产生有效学习证据的 **Section 集合** 为基础），并随学习进度自动扩大范围；AI 只能在该范围内分析、选重点、调整题型/难度与重新组合教材资源，不得把范围缩小为当前课时、当前 Section、当前 Unit、若干推荐项或当前薄弱项。
- 六个入口的图标各不相同；相邻入口的底色不相同（使用同一套低饱和色彩交替）。
- 题量随资源：有多少资源就用多少资源，没有固定题数；资源不足时不硬凑（允许 0 题）。
- 各入口的资源范围按各自正式规则（practice 的规则不得复制给其他入口）：**跟读练习**以当前 Section 为主要教材上下文（Unit 级词表 / 句表可作当前 Unit 辅助资源，**不得因当前 Section 无资源就扩大到整个 Unit 的未来 Section**）；**本课检测** = 当前 Section 的综合检测（**不得**因为自主练习使用已学 Section 集合就同步扩大到已学 Section；check ≠ practice）；Unit 级资源（词表 / 短语 / 词形）保持 Unit 级，**Unit 级资源出现 ≠ 对应 Section 已学**；正式资源不存在时允许空池，**不得用其他题型冒充**（听音阅读的正式资源模型另开阶段）。

练习页通用布局与交互（已确认）：

- 顶部保留进度条，不显示"第 X 题 / 共 X 题"；
- 主要内容位于屏幕中部，听音类的大扬声器位于中上部；
- 提交 / 下一题 / 重做 / 完成等主要操作位于底部操作区；
- 单词、句子答案输入框内文字水平居中；
- 界面能表达功能时不再增加重复说明文字。

实现现状只在 `demo/README.md` 中描述：Demo 的确定性模拟 AI、Spike 输出与 Demo 缓存属于验证机制，
不等于正式生产实现；正式 AI 接入按《AI 教材习题生成与题库入库流程规范》单独实施。

学习页负责：

- 展示教材内容类型
- 允许孩子选择Unit或具体学习内容
- 直接进入学习/练习
- 产生真实学习证据
- 在学习过程中提供必要的就地AI帮助

正常学习任务不超过 3 次操作进入真正学习状态：

```text
学习
→ Unit / 内容选择
→ 直接开始学习
```

### 5.2 教材内容的展示与入口边界（2026-09-26 同步）

**产品形态**

- 本应用是**单教材应用**；
- **不是多教材平台**。

**日常学习入口**

- 孩子选择当前 Section 后，可以直接从首页六个学习入口自主进入学习；
- **不要求先进入教材原文页**。

**教材原文页**

- **听读课文**（原「教材原文页」= `GET /unit/<slug>/text`）**经 2026-09-30 正式产品决策已升级为菜单入口**（首页六个学习入口之一），**跟随当前课时进度**（在哪个 Unit 就显示哪个 Unit）；
- **不是孩子进入日常学习的前置步骤**；
- 定位为：

> 教材音频对应内容的查看与播放页。

**教材中心（如保留）**

- 职责是**教材目录浏览与内容查阅**；
- **不替代首页学习主流程**；
- 不为了符合数据库结构而强制展示 Section / Activity 等内部解析层级。

**数据展示边界**

> 教材数据完整保留（词汇、短语、句型、练习、音频等），**不等于前端全部展示**。
> 教材原文展示页只展示与官方教材音频**可靠对应**的教材文本内容；不追求把整本教材全部文字搬进 APP。
> 播放入口贴合自然段或可靠对应文本，不逐句堆叠喇叭按钮；无可靠句子级映射时使用完整活动音频，不伪造句子切片。

### 5.3 菜单与目录规则（2026-09-27 同步）

> 规则全文与唯一权威记录见《最高指导原则与开发规范 V1.3》第二十九章 §15；本节为产品/UI 层同口径摘要。

**Section 选择入口与目录**

- 首页「当前课时」选择器是**唯一正式的 Section 选择入口**；完整教材目录为 **8 组、46 个 Section**，
  **不按题目或资源数量删减**。
- Section 是教材目录与当前学习进度的实际粒度；Unit 仅用于组织与聚合；不存在独立 Lesson 实体
  （`lesson` / `lesson_key` / `?lesson=` / `zx_lesson` 仅为承载 `section_key` 的历史代码命名）。
- Section 是目录与当前课程**选择**粒度，**不因此要求每个 Section 都必须成为独立页面**。

**正式学习功能集合与入口显隐**

- 六项功能为**正式学习功能集合**；**主页与次页**中显示哪些入口，按当前所选 Section 的**真实可调用资源**决定
  （见 §5.1 前置说明；**不得**用 Unit 资源总量代替；**入口显隐与统计数字是不同概念**，不得用候选资源数 /
  已完成数 / 未完成数判断入口是否可用）。
- **入口内部模式同规则**：`听音辨意` 的 `单词听辨｜句子听辨` 只显示**当前 Section 有资源的模式**
  （模式显隐与题目筛选同源，不另建判断）；默认模式无资源时按 `单词听辨 → 句子听辨` 改选
  第一个有资源的模式；两种模式均无资源时显示真实空状态且不显示无资源模式标签；**不得**切换 Section 或
  借用其他 Section 资源。细则以《最高指导原则与开发规范 V1.3》第二十九章 **§15** 为准。

**Appendix**

- Appendix **保留在完整教材目录与「当前课时」选择器中**；
- **不是普通教学 Unit**，**不强行进入六项功能入口**；
- 不得因其不进入入口而从目录或原始数据中删除；不得伪装成普通 Unit；不得为凑齐入口制造无依据的学习内容；
- Appendix 是否开放某项功能，以**实际资源**为依据（不得仅因它在目录中就推定应开放六项）。

**零题 Section 与空状态**

- 目录层：保留真实目录位置、名称与顺序；
- 功能入口层：按当前 Section 的真实资源决定是否显示该功能入口；
- 功能内容层：无资源时如实呈现真实空状态，不伪造、不静默替换；不得用其他 Section 的资源冒充当前 Section。

**Unit 与次级内容页**

- **`/unit/<slug>/text` 已升级为菜单入口「听读课文」（2026-09-30 正式决策，跟随当前课时进度）**；`/unit/<slug>/resources`、`/unit/<slug>/exercises` 等现存页面仍定位为**次级内容页**，
  不与首页正式学习功能入口并列成为一级学习主入口，也不得自动提升为一级入口（除非后续有正式产品决策）；
- 不得因次级页面存在而恢复旧 Unit 菜单或旧训练岛。

**统计语义**

- 候选资源数 / 已完成数 / 未完成数是不同指标，必须分别命名与定义，并说明统计范围与资源口径；
- 首页与功能页展示同一指标时使用相同范围与计算口径；不同范围、不同语义的数字不得用同一标签呈现或直接比较；
- 统计口径应尽可能与对应功能实际资源池和学习范围一致；
- 本节只同步统计**原则**，不规定未经核实的具体计算公式，也不修改统计实现（细则见 V1.3 第二十九章 §15）。

## 6. 进展页

进展页回答：我到底学会了多少？

进展页必须区分：

- 学习进度
- 掌握程度
- 需要巩固内容
- 最近表现变化

学习进度 ≠ 掌握程度。

禁止使用“学习完成60% = 掌握60%”。

## 7. 页面层级最小化原则

### 规则1：一级页面不超过3个

首页 / 学习 / 进展。

### 规则2：学习任务快速进入

正常任务不超过3次操作进入学习状态。

### 规则3：能当前页完成，不新建页面

结果、掌握状态、AI评价和下一步建议尽量在同一结果区域完成。

### 规则4：说明页不得成为学习必经路径

教材说明、学习目标说明、AI说明、知识点长介绍、数据来源说明和教材引用说明不得强制插入学习路径。

### 规则5：知识点详情不是必经页面

能直接学习就直接学习；详情只在确实需要时提供。

### 规则6：结果、评价、建议尽量合并

推荐：

```text
学习
→ 结果 + 掌握状态 + AI评价 + 下一步建议
→ 继续 / 结束
```

## 8. 统一学习闭环

所有学习类型尽量遵循：

```text
进入
→ 学习 / 练习
→ 产生学习证据
→ 结果
→ AI分析 / 评价
→ 下一步建议
→ 孩子决定是否继续
```

核心不是完成任务，而是产生学习证据并给出有意义反馈。

## 9. AI存在方式

AI是系统能力，不是一级“AI老师页面”。

AI分别存在于：

- 首页：分析整体学习状态
- 学习过程中：帮助理解当前问题
- 结果区域：解释当前表现
- 进展页面：分析长期变化

AI职责：分析 → 评估 → 反馈 → 建议。

没有足够学习证据时，系统必须输出“暂时无法形成可靠评价”，不得虚构掌握评价。

AI只能建议，孩子决定是否继续、选择什么内容、何时学习。

AI 出题的范围与入库规则不在本文件展开（本文件只放指针，不复制细则）：AI 在题库中限于【补干扰项 / 按音频补全教材文本挖空 / 依据教材资源出题】，
入库目标为 `questionbank.db`（作为素材，须过确定性闸门与人工审核）。细则见《最高指导原则与开发规范 V1.3》第二十九章 §16、§17，
以及《AI 教材习题生成与题库入库流程规范》。

## 10. 有效信息优先原则

任何文字、数字、按钮、卡片必须至少满足一项：

1. 提供真实学习信息
2. 帮助孩子完成学习
3. 帮助孩子理解自己的学习表现
4. 帮助孩子做出下一步学习选择

均不满足则应删除。

优先展示：

- 学了什么
- 学了多少
- 掌握了什么
- 哪些不稳定
- 哪些需要巩固
- 最近表现如何
- AI为什么这样判断
- 下一步建议什么

## 11. V2 视觉原则

V2视觉基线：Clean Modern Learning。

要求：

- 简洁
- 清晰
- 专业
- 安静
- 信息优先
- 学习优先

禁止：

- 游戏化
- 儿童化
- 糖果色
- 粉紫渐变
- 积分
- 排名
- 徽章
- 大量动画
- 大量装饰性插画

## 12. 跳转与反馈原则

所有跳转必须：

- 有即时响应
- 有明确状态
- 保持学习上下文
- 返回后不丢失当前学习位置
- 避免无意义中间页面

禁止点击后长时间无反馈；禁止完成学习后突然返回首页并丢失上下文。

## 13. V2 验收清单

V2页面设计必须逐项检查：

- 一级页面是否不超过3个
- 进入学习是否不超过3次操作
- 是否能在当前页完成结果、评价和建议
