## 规则

1. **Codex 开发时不得读取本目录作为依据**，也不得据此恢复任何旧的页面结构、数据规则、AI 规则或题量规则。
2. 本目录中的内容可能包含已被替代的旧方案，例如：
   - 旧首页结构与旧功能入口（词汇练习 / 短语练习 / 阅读练习 / 听辨练习 / 课文点读 / AI助教独立成页 等）；
   - 旧版本的最高指导原则条文（已被当前《最高指导原则与开发规范》替代的部分）；

3. 若本目录内容与 `docs/` 下的当前规范冲突，**一律以当前规范为准**。
