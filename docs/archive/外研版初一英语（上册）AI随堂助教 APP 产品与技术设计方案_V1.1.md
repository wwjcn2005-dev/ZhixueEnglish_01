## 1. V1.1 的产品定位调整

V1.0 的产品定位是“电子教材 + 可点读音频 + 轻量学习工具 + 学习证据 + AI随堂助教”。

V1.1 在此基础上把产品形态明确收敛为：

> **课堂同步型英语 AI 学习 APP**

核心体验固定为：

```text
极速对齐课堂
→ AI 随堂助教诊断
→ 今日 10 分钟课堂同步特训
→ 产生学习证据
→ AI 反馈
→ 我的进展
```

约束（不变）：

> 教材是主线，学习是核心，孩子做主，AI 做助手。

V1.1 明确区分两件事：

- **教材提供内容**：教材内容、课文、词汇表、短语句型、官方音频、教材原题。
- **系统负责组织**：系统把教材内容组织成孩子真正容易使用的训练（词汇 / 短语 / 阅读 / 听力），
  而不是把 APP 做成“教材 PDF + 一堆教材题目”的电子题库。

## 2. 首页重新定义（课堂同步首页）

首页不再回答“我有哪些功能”，只回答三个问题：

1. 我现在学到哪里了？
2. AI 怎么看？
3. 今天最值得做什么？

首页固定结构，自上而下：

```text
章节选择（七年级上册 + Unit 下拉切换）
→ AI 随堂助教（章节内容 + 该章节学习状态驱动）
→ 开启今日10分钟课堂同步特训（唯一最高优先级主行动）
→ 我的进展（家长可读的三维表达）
```

首页硬性约束：

- **只有一个最高优先级主行动**：`开启今日10分钟课堂同步特训`。
  不得出现第二个同等级主按钮，不得重新堆叠“开始学习 / 开始练习 / 今日任务 / AI推荐”。
- **顶部只负责“当前在看哪一章 + 可以切换章节”**，不承担任何学习时间统计
  （不显示“本周已学习 N 分钟”“今天已经学习 N 分钟”等）。学习时间统计若将来需要，
  属于“我的进展”或其他正式学习数据区域，不属于顶部，也不在本次新增。
- 首页不显示“我的名字”、个人欢迎语、与核心学习任务无关的身份展示。
- 首页不突出“教材原文 / 教材练习”作为主要入口（教材入口在“学习”一级页面内）。
- 首页不得出现：正确率、掌握率、雷达图、排名、积分、连续天数、徽章、任务清单、
  内部枚举与字段、AI 对话入口。
- 首页允许以**低强调的一行**提示“需要再学”的数量（V1.3 第二十章允许首页显示数量）。

### 2.1 章节选择（顶部唯一职责）

首页第一视觉区域是**章节选择器**（即“极速对齐课堂”，V1.1 修正后统一称为“章节选择”），
一眼可见当前章节，并且可以快速切换：

```text
七年级上册
Unit 1 · A new start ▼
```

职责边界（本条的准确含义）：

- 只告诉用户**当前在看哪个章节**，并允许快速切换；
- **不是**统计区、不是学习进度区、不是最近学习区、不是时间统计区、不是 AI 分析区；
- 顶部区域**彻底不承担学习时间统计**，也不把统计信息换个位置继续留在顶部。

选择组件必须**标准、清晰、移动端友好**，让家长和孩子在几秒内切换章节。

**教材层级事实（只读复核结论，2026-09-15）**：

- 当前真实教材为外研社《义务教育教科书·英语 七年级上册》（2022 年课程标准修订）。
- 真实层级为 **教材（七年级上册）→ Starter / Unit 1–6 / Appendix**。
- 教材正文内容块中出现 “Module” 次数为 **0**，出现 “Unit” 次数为 127。
- 因此教材**不存在 Module 层级**；V1.1 的课堂位置选择采用真实存在的两级：
  **教材册次（当前只有 1 本，以文字呈现）→ 单元（可切换的下拉选择）**。

禁止为了对齐某个 UI 草图而虚构 Module 层级（违反 V1.3 第四·5“教材真实性优先于开发便利”、
第五·3“所有识别结果必须可追溯”）。

选择组件约束：

- 使用原生下拉选择（移动端使用系统原生选择器），不引入第三方组件；
- 不使用 slug、unit_id、数据库字段等技术人员才看得懂的值；
- 切换章节后，首页的**全部内容**都随之对齐：AI 随堂助教、今日 10 分钟特训、
  学习内容入口、学习状态、我的进展；
- 不允许出现“顶部选择 Unit 2，但下面 AI 仍然显示 Unit 1”或“进展仍然是 Unit 1 数据”；
- 不新增独立的“设置页”。

## 3. AI 随堂助教（章节内容 + 学习状态驱动）

AI 随堂助教紧跟章节选择，作用是**分析 → 评估 → 反馈 → 建议**，并且必须形成：

```text
章节内容分析 → 学习前建议 → 学习行为产生 → 基于证据的学习情况 → 动态建议
```

### 3.1 第一次打开某个章节（没有任何学习行为）

此时**没有学习证据**，AI 只能回答“这一章需要学什么、应该掌握什么”，不得评价孩子。

结构：

```text
AI 随堂助教
  <章节名，例如 Unit 1 · A new start>
  <这一单元主要围绕……展开。>
  这一单元建议重点学习
    词汇：<来自该章节真实教材词表的重点词>
    短语：<来自该章节真实教材短语 / 教材句子的表达>
    句型 / 表达：<来自该章节真实教材句型>
  <先把课文、重点词汇和核心表达熟悉起来，再做针对性练习。>
```

首次进入**禁止**出现：“你掌握得很好”“你掌握较差”“你还有三个薄弱点”“AI发现你不会……”
等任何针对孩子的评价——因为没有学习证据。

### 3.2 再次打开章节（已经产生学习行为）

孩子产生学习行为（跟读、练习作答、课文点读、阅读、听力）后，AI 随堂助教必须读取
当前章节的学习状态并显示：

```text
AI 随堂助教
  <你已经完成了这一章的……>
  当前值得继续巩固
    1. <环节 / 内容> —— <为什么还需要巩固>
    2. <环节 / 内容> —— <可以怎么练>
```

此时才可以使用：已经完成什么、哪些资源已经学过、哪些训练还没有做、哪些地方出现过重复问题。

### 3.3 多次进入如何变化

每次打开章节都必须根据**当前学习行为重新计算**当前状态，形成阶段推进，例如：

```text
第一次：这一章建议先掌握 <重点词>、<重点短语>
学习后：词汇已经完成第一轮，当前短语应用还需要巩固
再训练：<已练环节>已经比较稳定，现在更适合通过课文理解和听力继续巩固
再之后：本章核心内容已经基本覆盖，可以继续练薄弱点，也可以先结束今天学习
```

### 3.4 硬性约束

约束：

- AI 是助手，不是老师：不得使用“你必须”“立即完成”“系统要求你”等强制语气。
- 不得制造虚假 AI 能力，不得出现伪精确分数（如“发音 88 分”）。
- 诊断必须与教材内容对应：**重点内容必须来自当前章节的真实教材内容**；
  不同章节必须有不同内容，不得所有 Unit 都显示同一组重点。
- 如果某章节真实资源不足，如实显示已有内容，不得为了页面丰富而虚构教材知识点。
- 没有足够学习证据时，正式系统必须输出“暂时无法形成可靠评价”；Demo 阶段允许使用
  隔离的虚拟诊断数据，但页面必须明确标注为演示数据。
- **不得用访问次数伪造学习进步**：刷新页面、打开页面、切换章节、返回首页都不得改变
  学习状态；只有真实学习行为（跟读完成、练习作答、课文点读、阅读完成、听力完成）
  才能改变它。
- 学习状态必须**按章节隔离**：某个章节的学习行为不得影响其它章节。
- 不调用真实 AI API（Demo 阶段 AI 调用 = 0）。

## 4. 今日 10 分钟课堂同步特训（核心行动）

点击首页唯一主行动后，进入一个连续学习流：

```text
课堂位置
→ AI 诊断
→ 课文点读
→ 词汇跟读
→ 词汇练习
→ 短语练习
→ 阅读练习
→ 听力练习
→ 学习结果
→ AI 反馈
→ 我的进展
```

约束：

- 不要求孩子每次完成所有环节；系统允许根据今日训练状态结束。
- AI 负责组织和建议（例如“今天可以先巩固这 3 个词”），**孩子决定是否继续、换内容或结束**。
- 每个环节之间必须有自然的“下一步”衔接，不得出现孤立功能页。
- 不出现分数动画、金币、徽章、排名、游戏化奖励。
- 特训时间模型沿用 V1.0 第 16 章“平日 10–15 分钟模型”。

## 5. 课文点读（取代“教材原文 + 阅读”两个入口）

原“教材原文”与“阅读”合并为**课文点读**。

产品理念：

> **教材本身就是播放器。**

要求（沿用并强化 V1.0 第 4、6、7、8 章）：

- 显示真实教材内容，保留教材层级（Unit → Section → 课文/对话）。
- 句子/段落作为音频点击区域；有音频的内容使用非常轻微的背景/边界提示。
- 点击即可播放；当前播放内容有清晰但克制的高亮。
- 优先使用 VERIFIED sentence-level audio；没有 VERIFIED 句子时间的位置只能使用
  **activity-level audio**，并在页面上明确标注“整段，未做句子切分”。
- 不得猜测句子时间；不得使用 CANDIDATE / REJECTED / ASR 猜测结果作为正式热点；
  不得为了 UI 方便切割官方音频。
- 现有 PDF、MP3 与 12 条 VERIFIED sentence-level audio（Unit 1）必须继续使用，不重新制作。

“阅读练习”不再作为独立的“阅读功能入口”，而是课文点读之后的一个训练环节
（见第 7 章）。

## 6. 训练按学习目标组织（取消“教材练习”作为主要产品入口）

用户看到的学习训练按照学习目标组织：

```text
词汇跟读 → 词汇练习 → 短语练习 → 阅读练习 → 听力练习
```

约束：

- 首页与 Unit 主入口不再突出“教材练习”。
- 教材原题资源保留在系统中，不删除、不修改；只作为低强调的次要入口呈现
  （教材原题仍然是教材事实的一部分，见 V1.3 第七章）。
- 系统自建练习必须：服务明确教材学习目标；针对已经暴露的薄弱点；帮助理解或巩固教材。
- 不得脱离教材制造大量随机英语题。
- 演示阶段的练习题必须满足：参考答案可由教材内容本身核对（教材原文句子、
  教材词表释义、教材句型），并且页面明确标注是演示题、不是教材答案。
- 教材原题在人工核验答案之前仍然**不判分**（V1.3 第七·9）。

### 6.1 词汇跟读（连续学习体验）

```text
顶部：播放教材标准音
中间：单词 / 中文义 / 简短教材语境（有音标则显示）
底部：录音 / 再读一次 / 回放自己的录音
切换：左右滑动进入下一个单词（不返回列表）
```

- 必须形成“听 → 跟读 → 左滑 → 下一个”的连续训练。
- 教材语境必须来自真实教材文本；找不到语境时不编造，改为显示教材词表出处。
- 跟读只记录“发生过一次跟读”，不生成任何发音分数（V1.0 第 9 章继续有效）。

### 6.2 词汇练习

```text
顶部：标准音频播放
中间：题目
下方：选项（选择 / 判断 / 简短输入）
正确 → 轻量反馈 → 进入下一题
        （页面内连续作答，不来回跳页）
错误 → 不羞辱、不扣分、给出简短提示 → 允许继续
```

- 题目来源为该单元真实教材词表与官方逐词音频。
- 不用红绿对错暗示羞辱孩子；不使用分数动画、金币、徽章、排名。

### 6.3 短语练习

- 使用真实 Unit 1 教材短语与教材句子中的表达，包括
  `make good use of`、`share some thoughts` 以及其他真实 Unit 1 短语。
- 题型：意思选择、搭配选择、句子填空、语境判断。
- 句子填空的答案必须来自教材原句本身。

### 6.4 阅读练习

- 建立在 Unit 1 已有教材内容之上：文章理解、信息定位、简单判断、句意理解。
- 题干与答案必须可由教材课文内容核对，不得重新制作一个与教材无关的“阅读训练网站”。

### 6.5 听力练习

- 必须使用已有 MP3 资源：Unit 1 已确认音频、已确认 activity-level audio、
  已有 sentence-level audio。
- 不得新跑 ASR、不得新切音频、不得猜测时间、不得制作假的语音评分。
- 只有存在 VERIFIED 句子级音频的单元才能提供“听句子选答案”这类可核验的听力练习；
  没有 VERIFIED 句子级音频的单元，如实说明并引导孩子使用课文点读里的
  activity-level 音频，不伪造题目答案。

## 7. 我的进展（家长可读的长期反馈入口）

“我的进展”是 V1.1 的重要产品结构，也是底部导航的第三项。

它不是普通统计页，首要目标是让**不懂英语的家长**在几秒内看懂孩子这一周吸收了什么：

> “孩子这周课文大体学得不错，句型语法还有一些问题，口语已经练了几次。”

### 7.1 三个维度

| 维度 | 表达方式 | 示例 |
| --- | --- | --- |
| 课文理解 | 进度条 + 百分比 + 一句话解释 | `88%` `本周 Unit 1 课文理解较稳定` |
| 句型语法 | 进度条 + 百分比 + 一句话解释 | `60%` `部分句型还需要继续巩固` |
| 口语练习 | **次数**（不是分数）+ 一句话解释 | `6 次` `本周完成 6 次跟读` |

三个维度必须**跟随当前章节**：切换章节后，首页与“我的进展”页显示的是该章节自己的
进展数值，不允许所有章节显示同一组数字。

### 7.2 命名与证据约束

- 正式产品统一使用 **口语练习**，不使用“口语发音评分”。
- **不得把“录了一次音”判断为“发音 88 分”。**
- 不得把跟读次数、录音时长、是否点击播放直接等同于发音能力、口语能力或掌握度。
- `课文理解 88%` 与 `句型语法 60%` 只有在存在真实、可解释的学习证据支撑时，
  才能进入正式数据阶段；Demo 阶段可以使用虚拟数值，但必须明确标注为演示数据。
- 没有足够学习证据时不得生成精确能力分数（V1.3 第二十四·2）。
- 家长可读，但不得出现 knowledge_id、evidence_id、mastery_state、API 状态、
  数据库字段等技术指标。

## 9. 学习证据与分数规则（V1.1 强化）

继承 V1.3 第二十二、二十四章与 V1.0 第 18 章，V1.1 强调：

1. 学习证据来自真实学习行为（主动回忆、练习作答、跟读、听力、阅读、跨日表现）。
2. 自评、完成动作（“我完成了”）、音频播放行为**不构成正式判断证据**。
3. 没有足够证据，就不产生掌握评价，也不产生精确能力分数。
4. 一次跟读只表示“发生过一次跟读”，不表示口语能力。
5. Demo 数值只存在于 Demo 数据层（`web/demo_data.py`），
   **不得写入正式 learning.db，不得伪装成真实学习记录**。

## 12. 与 V1.0 / V2.0 / V1.3 的一致性说明
