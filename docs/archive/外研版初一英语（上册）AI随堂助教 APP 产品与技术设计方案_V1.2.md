V1.2 是在 V1.1 基础上的**产品体验收敛**：减少无用信息、减少页面层级、强化教材入口、
强化学习任务本身，并把词汇跟读 / 词汇练习 / 句子跟读做成真正适合孩子使用的学习页面。
本文件不推翻 V1.1 的首页结构、章节选择、AI 章节状态驱动、我的进展三维度等已确认原则。

### 0.1 第二版 Demo（UI/交互实验）说明 —— 2026-09-15

本轮为**面向人工体验的 Demo UI/交互重构**（不是正式功能开发），用于验证新的产品方向。
正式基线仍以本文件 V1.2 为准；以下内容属**候选方案**，需产品确认后再决定是否升级版本：

1. **首页 = 今天学什么**：章节选择 → 功能入口列表（词汇跟读 / 词汇练习 / 短语练习 /
   阅读练习 / 听辨练习（有资源才显示）/ **课文点读放在最后**）→ 我的进展。
   入口不使用数字编号，每个入口为独立圆角浅色块（统一线性 SVG 图标 + 名称 + 右侧状态）。
2. **AI助教独立成页**：首页不再堆 AI 分析大卡；AI助教页给出「单元总结（章节 + 学习状态驱动）
   + 需要加强的语法与词汇（最多 3 项）」，不做聊天界面。
3. **课文点读 = 段落文本 ↔ 段落音频**：每段只播放属于它自己的官方录音区间，
   播放时整段高亮；不再使用逐词同步，也不用一小段文本播放整篇长音频；
   教材原页（原书页面 + 音频热点）作为次要入口保留。
4. **单词跟读**：单词居中 → 原音播放 → 麦克风跟读（录音态动效）→「正在分析」→
   **跟读结果（演示数据）**：完整度 / 词语表现 / 需要注意的词 / 建议 / 再读一次。
   **明确标注为演示结果，不产生任何精确发音分数**；当前没有真实发音评测能力，
   词级发音判断仍按 V1.2 §5.2 处理（未授权不实现、不伪造）。
5. **视觉**：以留白、浅色块、圆角、字级与图标区分区域，减少横线/竖线分隔；
   活动、练习、跟读、点读各用不同低饱和主色；进度条按维度使用不同低饱和色。

## 1. 顶部只做章节选择（V1.2 进一步极简）

首页顶部只保留两行：

```text
七年级上册英语
[ Unit 1 · A new start ▼ ]
```

必须删除顶部原有的其它信息：学习时间、本周/今日学习时间、出版社、课程标准、
教材详细身份信息、其它统计与状态。顶部**唯一职责**是：告诉孩子当前在看哪一章，并允许快速切换。

切换章节后，首页全部内容跟随：AI 随堂助教 → 今日 10 分钟特训 → 我的进展。

## 2. AI 随堂助教：只挑最重要的 3 个（V1.2 收敛）

### 2.1 第一次打开（没有学习证据）

不分类、不罗列整章知识点、不做统计，只提出 **最值得先学的 3 个知识点**：

```text
AI 随堂助教
  <这一单元主要围绕……展开。>
  这一章最值得先学的 3 个
    1. make good use of —— 好好利用 · 换个句子再用一次
    2. share some thoughts —— 分享一些想法 · 换个句子再用一次
    3. try your best —— 尽你最大的努力 · 换个句子再用一次
```

约束：

- **最多 3 项**；不出现“词汇 / 短语 / 句型 / 语法 / 阅读 / 听力”的分类堆叠；
- 每一项都必须来自**当前章节的真实教材内容**（教材句子里的表达 / 教材词表重点词 /
  教材短语 / 教材句型），不虚构、不凑数；
- 没有学习证据时**不得评价孩子**（不得出现“你已经掌握”“你还有薄弱点”等）；
- 不同章节必须给出不同内容。

### 2.2 有学习行为之后

孩子真的完成学习行为（跟读、练习作答、课文点读、句子跟读、阶段测）后，
AI 才可以说明“现在学得怎么样”，并且**最多仍然只显示 3 项**：

```text
AI 随堂助教
  <你已经完成了这一章的……>
  还有 3 个地方值得再巩固
    1. 短语练习 —— 还需要结合教材句子再练一次
    2. 听力练习 —— 可以用教材原声再听一次
    3. 句子跟读 —— 可以挑一句教材原句再录一遍
```

### 2.3 状态规则（沿用 V1.1）

- 状态按章节隔离；打开页面、刷新页面、浏览章节、切换章节都**不产生“学习进步”**；
- 只有真实学习行为才改变状态（Demo 阶段为本机隔离状态，不写 learning.db）；
- 没有足够证据不做精确能力分数。

## 3. 课文点读＝原书页面 + 音频热点（V1.2 核心变化）

课文点读不再是大段重新排版的纯文字，而是：

> **看原书 → 点哪里 → 听哪里。**

### 3.1 页面呈现

- 显示**真实教材原书页面**（彩色插图、原排版、原标题、原对话、原练习）——
  由现有教材 PDF **现场渲染**（只读派生，不修改、不重写、不导出教材文件）；
- 页面可上下翻页，显示当前教材印刷页码；
- 教材中有对应音频的区域叠加**轻量音频热点色块**，点击立即播放对应官方音频；
- 正在播放的热点做轻量高亮；
- 句子级热点使用 `audio_sentence_annotation` 中 **VERIFIED** 且时间有效的区间；
  没有句子级时间的位置使用**活动级整段音频**并明确标注“整段录音（未做句子切分）”。

### 3.2 热点必须真实可追溯

- 热点位置来自**教材 PDF 自己的文本层**：把教材文字与 PDF 文本块匹配，命中就用该
  **真实文本块坐标**；匹配不到时**不画热点**，而是在页面下方如实列出“本页还可以听”，
  并同样标明是整段录音还是教材原句；
- 禁止：猜测句子时间、切割官方音频、使用 CANDIDATE / REJECTED 数据当作正式热点、
  用 AI 推测热点位置。

### 3.3 与大段纯文字页面的关系

旧的“教材原文”纯文字页保留以兼容既有链路，但不再作为主要学习入口，
也不再继续增强；产品入口统一为「课文点读」。

## 4. 极简学习页（V1.2 新增的页面基线）

### 4.1 词汇跟读

一屏一个词，从上到下：

```text
进度条  6/10
单词（页面最大视觉焦点）
音标
词性
中文意思
例句（小字号、灰色、左对齐，不抢焦点）
底部：小扬声器（播放/暂停标准音） ｜ 大麦克风（开始跟读） ｜ 返回
```

- 进入页面**自动播放**该词的官方标准音；左右滑动换词后自动播放下一词；
- 孩子点麦克风录音，录音完成后**立即**对**孩子自己的这次录音**做简单反馈；
- 页面不得出现：AI 分析、学习建议、学习时间、完成率、分数、技术状态、录音波形、
  录音时长、“请点击麦克风”等说明、大段解释与多余按钮。

### 4.2 词汇练习

一屏一题，左右滑动卡片：

```text
进度条  6/10
🔊（进入自动播放标准音，可播放/暂停）
这个词是什么意思？
A / B / C / D
确定  →  判断 → 简单反馈 → 下一张卡片
```

- 选项与参考答案来自当前章节真实教材词表；干扰项同样来自同一课的真实释义；
- 不出现分数动画、金币、徽章、排名等游戏化内容。

### 4.3 句子跟读

与词汇跟读**完全一致的操作逻辑**：进度条 → 当前教材句子（唯一视觉焦点）→
底部 小扬声器 / 大麦克风 / 返回；进入自动播放官方句子音频，左右滑动换句并自动播放。

- 页面不出现：中文翻译、语法讲解、AI 长解释、单词解释、学习建议、技术状态、波形、评分报告。

## 5. AI 口语评价的能力边界（V1.2 审计结论）

### 5.1 只读审计结论

| 能力 | 现状 |
| --- | --- |
| 录音 | 已有（浏览器 MediaRecorder + getUserMedia，仅在浏览器内存中，不上传） |
| 音频保存 / 读取 | 仅浏览器 blob 与 `<audio>` 回放；服务端不接收孩子录音 |
| 官方音频播放 | 已有（官方 MP3 + 逐词音频 + 已核验句子区间） |
| AI grading | `web/ai_grading.py` 为规则预检入口，`AI_PROVIDER = None`（未接入） |
| DeepSeek | 未接入（无接口、无 Key） |
| Whisper / WhisperX | 主运行环境**没有**，且本机**没有**已下载的模型权重 |
| 本地音频处理 | 主运行环境无 numpy / scipy / soundfile |

**分类结论**：

- 对**孩子录音本身的可测特征**做分析：**B（部分具备，只需最小前端组件，不新增依赖）**；
- 对**发音 / 词级读音正确性**做可靠判断：**C（当前不具备可靠实现条件）**。

### 5.2 V1.2 的实现边界（不得越过）

允许（并且已经实现）：

- 录音完成后立即分析**孩子这一次录音本身**的可测事实：录音时长、峰值音量、
  有效语音占比（有没有在读/是否断断续续）、平均音量；
- 反馈只有几句，例如“这次读得很清楚，可以继续。”“这次声音有点小，再读一次。”
  “没有录到声音，检查一下麦克风，再读一次。”；
- 支持重新录音、左右滑动换下一个词/句。

禁止：

- 生成“发音 87 分”“清晰度 92%”“节奏 88%”“完整度 95%”等伪精确分数；
- 把**波形相似度**直接当作发音正确率；
- 因为 ASR 识别成同样文字就直接宣称“发音正确”；
- 在没有可靠词级发音判断能力时，假装指出“某个词读错了”。

> **尚未实现（需要额外授权）**：词级发音判断（例如“nervous 再读一次”并让该词变色）。
> 实现它需要语音识别 / 发音评测模型（新依赖或新服务），按 V1.2 §二十七 的规定，
> 必须先报告并获得授权后再实施。V1.2 期间**不安装新依赖、不下载模型、不调用云端语音 API**。

## 6. 学习体系内部：周六巩固 / 周日阶段巩固（V1.2 新增）

周末学习属于**学习体系内部**，首页不出现。

### 6.1 周六 · 本周巩固

按本周学习证据组织：重点词汇、核心短语、重点句型、课文理解，以及“本周还可以补一补”的内容
（来自本机该章节学习状态里还没做的环节）。

### 6.2 周日 · 阶段巩固 / 阶段测

- 对这一阶段学过的内容做一次综合检查，覆盖词汇 / 短语与表达 / 阅读 / 听力；
- 使用当前章节真实教材内容出题，**不强制**，由孩子决定是否做；
- 完成后**产生新的学习证据**，AI 随堂助教据此更新“下一阶段最值得继续巩固什么”；
- 不做排名、不打分等级、不做游戏化奖励。

---

## 7. 信息减法审查（V1.2 全局要求）

任何页面上，如果一个信息不能帮助孩子完成当前任务，就删除。重点清理：

- 重复标题、重复章节名称、大段说明、多余统计、多余卡片、多余按钮、
  多余 AI 说明、多余状态、工程调试信息与技术术语。

保留判据：**提供真实学习信息 / 帮助完成学习 / 帮助理解学习表现 / 帮助选择下一步**，
四项均不满足则删除。

---

## 8. 数据保护与成本（V1.2 不变）

- AI 调用 = 0；ASR 调用 = 0（本阶段未使用任何 ASR）
- 正式 `learning.db`、contentpack、教材 PDF、教材 MP3、sentence annotation 只读
- 教材 PDF 页面图片为**现场渲染的只读派生视图**，不修改、不导出、不替换原始教材
- 需要验证写入行为时只使用临时数据库副本
