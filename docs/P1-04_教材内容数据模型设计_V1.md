## 1. P1-04 目标

回答一个工程问题：

> 用什么稳定、可扩展、可追溯的数据结构，把真实外研版七年级上册教材、原始音频、教材任务、词汇、句型、语法、学习目标，以及未来孩子的学习表现连接起来，同时保证教材始终是权威源？

具体目标：

1. 教材身份可区分，防止旧版、新版、其他出版社教材混入同一套内容。
2. 教材层级可承载 `Textbook → Unit → Section → Activity → ContentBlock`，且不破坏真实教材结构。
3. 页面与页码映射允许特殊情况（`textbook_page` 可为 `None`）。
4. 原始内容与程序处理结果严格分离（`text_raw` / `text_normalized`）。
5. 任何重要教材内容都能追溯回 PDF 的具体位置。
6. Activity 是可组合的容器，而不是一行文本。
7. 音频先候选后确认，绝不自动确认。
8. 教材派生资源（词汇 / 短语 / 句型 / 语法）必须挂教材来源。
9. 学习目标区分“教材明示 / 结构整理 / AI 建议”。
10. AI 内容与用户学习数据从设计层面与教材权威内容隔离。

## 2. 四层数据架构

```text
L1 权威教材内容层   ← 唯一事实源，仅来自教材 PDF / 官方音频，只读可追溯
        ↓ 派生（只读引用）
L2 教材派生学习资源层  ← 词汇 / 短语 / 句型 / 语法 / 学习目标，必须挂来源
        ↓ 引用
L3 AI 辅助层        ← AI 解释 / 提示 / 诊断 / 建议 / 生成练习，只能引用，不能反写
        ↓ 只读引用
L4 孩子学习表现层    ← 学习会话 / 作答 / 掌握状态 / 巩固，只引用 ID，不复制教材正文
```

三条硬性约束：

1. L3、L4 对 L1 只有读权限；任何写入必须经过人工审核通道。
2. L2 的每条记录必须至少有一个指向 L1 的 `source_ref`，不允许存在“没有教材出处”的词汇、句型、语法条目。
3. 所有层级以 `text_raw` 为准，`text_normalized` 只是程序处理形式，永远不覆盖原文。

未来若建库，四层对应四个独立命名空间：`l1_textbook` / `l2_derived` / `l3_ai` / `l4_learner`。

## 4. TextbookEdition（教材版本）

```text
TextbookEdition
├── textbook_id            稳定主键，由下方字段确定性生成（不手写字面量）
├── publisher              出版社，如：外语教学与研究出版社
├── title                  教材名，如：义务教育教科书·英语 七年级上册
├── grade                  七年级
├── volume                 上册
├── curriculum_standard    依据课标，如：义务教育英语课程标准（2022年版）
├── edition_label          版次/修订标识
├── language               英语
├── is_official            是否正式教材版本
├── schema_version         模型版本
└── source_artifact_ids    → SourceArtifact[]
```

`textbook_id` 建议规则：`<publisher_code>-<lang>-<grade><volume>-<curriculum>`，由字段拼出，**不硬编码任何统计数字**。

作用：未来出现旧 Module 版、新修订版、其他出版社教材时，只要 `textbook_id` 不同，就是两套互相隔离的教材，课程结构、词汇资源、学习记录不会串味。

## 6. Unit（单元）

```text
Unit
├── unit_id               <textbook_id>:<UNIT_KEY>
├── textbook_id
├── unit_kind             starter / unit / appendix
├── unit_number           1..6（Starter、Appendix 为空）
├── title                 单元标题，必须来自 PDF 实际版面
├── title_evidence_ids    → Evidence[]
├── pdf_page_start
├── pdf_page_end
├── textbook_page_start  可为 null
├── textbook_page_end    可为 null
├── review_status
└── section_ids           → Section[]
```

约束：

- 单元边界以 PDF 自带书签为主证据，并与单元起始页真实版面标题互相校验。
- 不允许根据旧版教材的 Module 结构推断本册单元结构。

## 7. Section（板块）

```text
Section
├── section_id            <unit_id>:<SECTION_KEY>
├── unit_id
├── title                 如：Understanding ideas
├── section_key           规范化键（如 understanding_ideas）
├── pdf_page_start
├── textbook_page_start   可为 null
├── evidence_ids          → Evidence[]（标题文本、字号、位置）
├── review_status
└── activity_ids          → Activity[]
```

约束：

- 不假设所有 Unit 的 Section 完全一致，必须以实际页面为准。
- 标题允许与相邻文字合并绘制（如 `Make a profile of an animal.Presenting ideas`），模型只记录证据与判定依据。

## 8. Activity（活动）

Activity 是可组合容器，**禁止简化为 `activity.text`**。

```text
Activity
├── activity_id            <section_id>:A<number>
├── section_id
├── activity_number        教材真实编号，不重新编号
├── number_evidence_id     → Evidence（编号 span 的 bbox / 字号 / 字体）
├── instruction_block_id   → ContentBlock（指令）
├── content_block_ids      → ContentBlock[]（对话、阅读材料、例句、表格、图片文字…）
├── sub_question_ids       → SubQuestion[]
├── sidebar_block_ids      → ContentBlock[]（支撑性辅助框）
├── page_span              [pdf_page, …]，允许跨页
├── textbook_page_span
├── continuation           none / continues_to_next_page / from_previous_page
├── boundary_status        OK / NEED_REVIEW
├── boundary_evidence_ids  → Evidence[]（侧栏位置、页底位置、相邻活动起点）
└── review_status
```

约束：

- Activity 编号在各 Section 内独立生效，不跨 Section 连续。
- 教材原编号必须原样保留，解析器不得自行补号或改号。
- 若无法可靠判断边界，保留 `boundary_status = NEED_REVIEW`，不得猜测。

## 9. ContentBlock（教材内容原子）

```text
ContentBlock
├── block_id               <page_id>:B<序号>
├── page_id
├── text_raw               尽可能接近源文件的原始文本（保留全角标点与原始字形）
├── text_normalized        程序处理形式（NFKC 归一化、fi/fl 连字还原）
├── block_kind             instruction / dialogue / reading_text / example_sentence /
│                          word_list / table / table_cell / sidebar_tip / learning_hint /
│                          caption / exercise_item / heading / footer_text / other
├── layout_role            body / heading / sidebar / footer / section_title / unit_number
├── reading_order          重建后的阅读序号
├── sidebar_relation       belongs_to_activity / separate_region / auxiliary_same_column / none
├── evidence_ids           → Evidence[]
└── review_status
```

原则：

- 一个 ContentBlock 只承载一种语义角色；复杂内容由多个 block 组合。
- `text_normalized` 是程序处理形式，**不是教材原文**。
- 原始块与派生块都必须保留，不允许用处理结果覆盖原始结果。

## 10. Page（页面）

```text
Page
├── page_id                <textbook_id>:P<pdf_page>
├── textbook_id
├── pdf_page               1..178
├── textbook_page          可为 null（封面/目录/附录分隔/后记/封底等）
├── textbook_page_evidence footer_confirmed / derived_only /
│                          front_matter / back_cover / no_printed_page_number
├── page_role              front_cover / credits / toc / content / unit_opener /
│                          appendix_index / back_cover / unknown
├── width / height
├── layout_type            single_column / two_column / single_column_with_sidebar /
│                          mixed / dense_visual
├── reading_order_status   OK / OK_SIDEBAR_LAST / NEED_REVIEW
├── image_asset_ids        → ImageAsset[]
├── content_block_ids      → ContentBlock[]
└── review_status
```

页码规则：

1. 优先采用页脚中真实印刷页码（`footer_confirmed`）。
2. 页脚缺失时才允许使用 `PDF 页码 − 5` 推导，并记为 `derived_only`。
3. 封面、目录、附录分隔页、后记、封底等特殊页面，`textbook_page` 必须允许为 `None`，不得机械计算。

## 11. Evidence（证据链）

```text
Evidence
├── evidence_id
├── source_type            pdf_text / pdf_image / pdf_toc / filename_rule /
│                          parser_rule / manual_review
├── pdf_page
├── textbook_page          可为 null
├── bbox                   [x0, y0, x1, y1]
├── block_id / span_id     可空
├── font / font_size / flags  （仅当判定确实依赖排版时记录）
├── extraction_version     解析器版本与规则集（如 parser_v01 + P1-03-C）
└── note
```

追溯链：

```text
PDF
 ↓
PDF page
 ↓
textbook page
 ↓
bbox
 ↓
parser / extraction version
 ↓
review status
```

原则：教材重要内容必须能回到 PDF 的具体位置核对；不为“看起来完整”而增加无意义字段。

## 12. SubQuestion（子问题）

```text
SubQuestion
├── sub_question_id
├── activity_id
├── ordinal                教材中的小问编号（1、2、3…）
├── text_raw / text_normalized
├── evidence_ids           → Evidence[]
└── review_status
```

用于承载教材中成组出现的小问（例如阅读活动下的连续提问），避免把它们误判成独立 Activity。

## 13. ActivitySidebar（活动与辅助内容关系）

```text
ActivitySidebar
├── relation_id
├── activity_id            可为空（侧栏也可能不属于任何 Activity）
├── block_id               → ContentBlock
├── relation_type          supports_activity / belongs_to_activity /
│                          separate_region / auxiliary_same_column / unattached
├── relation_evidence_ids  → Evidence[]（水平/垂直 bbox 关系）
└── review_status
```

用途：表达“这是教材内容，但它与主要 Activity 的关系是什么”。例如 `Useful expressions`、`Learning to learn`、`Learning to think` 这类辅助框，可以：

- 明确支撑某活动 → `supports_activity`
- 位于独立区域（与活动正文列水平不相交）→ `separate_region`，不并入 Activity 主体
- 与活动正文同栏、归属无法可靠判断 → `auxiliary_same_column` + `NEED_REVIEW`

绝不允许把侧栏内容简单塞进 Activity 正文。

## 14. ImageAsset（图片资产）

```text
ImageAsset
├── image_id
├── page_id
├── xref
├── width / height
├── colorspace / filter
├── bbox                   版面位置（可得时）
├── block_id               对应图片 block（可得时）
├── tiny_fragment          是否为碎片（如 width < 50 或 height < 50）
└── review_status
```

原则：

- 原始图片信息不删除，碎片只做标记。
- 本阶段不导出图片、不做 OCR。
- 图片相关文字（图注、图片内文字）如进入模型，必须作为 ContentBlock 并挂 Evidence。

## 16. AudioMapping（音频映射，候选制）

```text
AudioMapping
├── mapping_id
├── audio_id
├── target_type            activity / section / content_block / unit
├── target_id
├── mapping_status         CANDIDATE / CONFIRMED_BY_HUMAN / REJECTED
├── confidence             0–1（候选期可空）
├── basis                  文件名规则 / 人工比对 / 音频内容核对
├── evidence_ids           → Evidence[]
├── reviewed_by / reviewed_at / review_note
└── is_active
```

铁律：

- 当前 54 个音频的映射**全部保持 `CANDIDATE`**。
- 不得因为文件名看起来吻合就改为 `CONFIRMED`。
- `CONFIRMED_BY_HUMAN` 只能由人工审核写入，且必须带 `reviewed_by` 与依据。

## 17. Transcript（听力原文 / 转写）

```text
Transcript
├── transcript_id
├── audio_id 或 content_block_id
├── transcript_kind        SOURCE / EXTRACTED / ASR_AI / HUMAN_TRANSCRIBED
├── text_raw / text_normalized
├── language
├── confidence             仅 ASR_AI 有意义
├── provider / model       AI 生成时必填
├── review_status          NEED_REVIEW / REVIEWED_OK / REJECTED
└── evidence_ids           → Evidence[]
```

铁律：`SOURCE`（教材/出版社提供）与 `ASR_AI`（AI 生成）是两类不同数据，模型层强制区分，界面层永远不能把 AI 转写呈现为“教材原文”。本阶段不生成任何 transcript。

## 18. 教材派生学习资源（Vocabulary / Phrase / SentencePattern / Grammar）

```text
VocabularyItem / PhraseItem / SentencePattern / GrammarPoint
├── item_id
├── textbook_id
├── surface_form            词 / 短语 / 句型 / 语法点的表层形式
├── lemma / phonetic / part_of_speech / meaning_zh
│                           （仅当来自教材可核对内容时才允许填写）
├── source_ref_ids          → SourceRef[]（必填，至少一条）
├── derivation_type         FROM_TEXTBOOK_LIST   （教材自身词汇表，如附录 Words and expressions）
│                           FROM_ACTIVITY_TEXT   （从教材活动/课文原文提取）
│                           FROM_SENTENCE         （由教材例句归纳）
├── review_status
└── created_from_snapshot_id
```

原则：

- 这些资源是**教材的派生物**，不是独立于教材的课程体系。
- 必须能回答：“这个词为什么出现在这里？”“这个句型来自教材哪个地方？”“这个语法点对应哪段教材内容？”
- 没有 `source_ref_ids` 的记录在模型层即非法。
- 教材附录词汇表（教材自己给出的）与从课文提取的词汇，可信度不同，必须用 `derivation_type` 区分。

## 19. SourceRef（来源引用）

```text
SourceRef
├── source_ref_id
├── source_type            content_block / activity / section / appendix_entry / audio
├── source_id
├── pdf_page / textbook_page（冗余便于检索，仍以 Evidence 为准）
├── quote_raw              教材原文片段（原文，不存 normalized）
└── quote_bbox             可空
```

用途：为 L2 派生资源、L3 AI 内容、L4 学习记录提供统一的“回到教材”的引用结构。

## 20. LearningGoal（学习目标）

```text
LearningGoal
├── goal_id
├── scope                  unit / section / activity
├── scope_id
├── statement_raw          原文表述
├── statement_normalized
├── goal_origin            TEXTBOOK_EXPLICIT / STRUCTURE_DERIVED / AI_SUGGESTED
├── source_ref_ids         → SourceRef[]（TEXTBOOK_EXPLICIT 必填）
├── review_status
└── visible_to_child
```

三类来源严格区分：

1. `TEXTBOOK_EXPLICIT`：教材明示的目标（如单元开篇 “After completing the unit, you will be able to …”）。
2. `STRUCTURE_DERIVED`：根据教材目录与板块结构整理出的目标。
3. `AI_SUGGESTED`：未来 AI 辅助分析给出的建议，属 L3，默认不作为学习任务展示。

绝不允许 AI 自行“创造教材标准”。

## 21. AIArtifact（AI 辅助层）

```text
AIArtifact
├── artifact_id
├── artifact_kind          explanation / hint / diagnosis / suggestion / generated_practice
├── target_layer           textbook_content / derived_resource / learner_activity
├── target_id              AI 只能“指向”，不能改写目标
├── context_ref_ids        → SourceRef[]（必须锚定教材或学习资源）
├── content_markdown
├── model / prompt_version / created_at
├── confidence
├── review_status          NEED_REVIEW / REVIEWED_OK / REJECTED
└── is_visible_to_child
```

隔离手段（三重）：

1. 命名空间隔离：`l1_textbook` / `l2_derived` / `l3_ai` / `l4_learner`。
2. 写入权限隔离：L1 只允许解析器 + 人工审核写入；L3/L4 对 L1/L2 只有读权限。
3. 呈现隔离：任何 AI 内容必须带来源标识，不得出现在“教材原文”视图中。

## 25. MasteryState（掌握状态）

```text
MasteryState
├── mastery_id
├── learner_id
├── target_id
├── mastery_level          未学习 / 正在学习 / 初步掌握 / 掌握较稳定 / 需要再次巩固
├── evidence_attempt_ids   → Attempt[]
└── updated_at
```

原则：**学校教材进度 ≠ 个人掌握度**。两者必须是独立实体，绝不互相覆盖。

## 27. 商业内容与用户数据隔离原则

1. **教材内容不是用户数据。** L1/L2 是商业/教材资产，L4 是个人数据，二者物理与逻辑分离。
2. **用户学习记录不能污染教材内容。** L4 只允许引用 L1/L2 的 ID，禁止复制、改写教材正文。
3. **AI 生成内容不能污染教材权威内容。** L3 永远不写入 L1/L2。
4. **教材原文只读。** 原始 PDF、图片、音频在任何阶段都不得被修改或覆盖。
5. **可信度分层。** 教材原文 > 教材派生资源 > 人工审核的 AI 内容 > 未审核的 AI 内容。
6. **可恢复。** 任何审核状态变更都应保留历史，不得物理删除。

## 33. P1-04 最终结论

1. 教材层级完整可用：`Textbook → Unit → Section → Activity → ContentBlock`，并保留 `Page`、`Evidence`、`SubQuestion`、`ActivitySidebar`、`ImageAsset` 等支撑实体。
2. 教材身份与源文件可验证：`TextbookEdition` + `SourceArtifact`（含 SHA256）确保不同版本教材互不混入。
3. 原始文本优先：`text_raw` 与 `text_normalized` 分列，程序处理永不覆盖原文。
4. 证据链完整：任何重要教材内容都能回到 PDF 页面、bbox、解析版本与审核状态。
5. Activity 是容器：包含指令、内容块、子问题、辅助内容、跨页与边界证据，不会退化为单字符串。
6. 音频先候选后确认：54 个音频全部保持 `CANDIDATE`，人工确认通道已预留。
7. 派生资源有出处：Vocabulary / Phrase / SentencePattern / Grammar 必须挂 `SourceRef`，不成体系化课程。
8. 学习目标分层：`TEXTBOOK_EXPLICIT` / `STRUCTURE_DERIVED` / `AI_SUGGESTED` 三类不混淆。
9. AI 与用户数据隔离：四层架构从命名空间、写入权限与界面呈现三方面保证 AI 内容与学习记录无法污染教材权威内容。
10. 不确定性被保留：当前 23 处边界 `NEED_REVIEW`、88 页阅读顺序 `NEED_REVIEW`、17 处编号缺口全部由模型显式承载，等待人工审核，而不是被猜测填平。

**P1-04 结论：模型设计完成，可作为后续结构化导入与学习模型建设的依据；在正式建库之前，仍需先完成 P1-03-C 遗留的 NEED_REVIEW 人工审核。**
