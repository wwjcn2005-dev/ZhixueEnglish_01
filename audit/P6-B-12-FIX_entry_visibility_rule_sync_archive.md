## 4. 本次正式确定的规则（与 V1.3 §15 同口径）

1. **统一显隐（主页 + 次页）**：主页与次页中的**所有正式学习功能入口**（不只首页六项），均按**当前 Section
   的实际可调用资源**决定是否显示；**不得**用整个 Unit 的资源总量（或 Unit 级聚合数）代替。
2. **无资源即隐藏入口，但目录完整**：当前 Section 无该功能所需资源时隐藏该功能入口；**不得**删除 Section、
   不得从完整目录 / 「当前课时」选择器中移除（仍保留 **8 组、46 个 Section**，含零资源 Section 与 Appendix）；
   **不得**静默切换到其他 Section，**不得**借用其他 Section 的资源。
3. **Appendix**：保留在教材目录与「当前课时」选择器中，**不是普通教学 Unit**、**不强行进入六项学习功能**；
   入口按**实际资源显式判断**，**不得通过吞掉异常**（服务层抛错后清空入口列表）来实现隐藏；
   **不得为此修改冻结服务层**（`learning/study_call_service.py`）。
4. **直接进入的空状态**：通过历史链接或其他路径**直接进入**无资源的功能页时，仍须显示**准确、面向孩子**的
   空状态；**不使用**"换个章节看看"等与事实不符的误导文案（无资源是资源事实，不是章节问题）。
5. **统计数字不作为入口显隐依据**：入口显隐 / 候选资源数 / 已完成数 / 未完成数是不同概念；
   不得用统计数字判断入口是否可用。
6. **不改变既有规则**：本次补充不改变完整目录、Section 进度粒度、Appendix 身份、六项功能集合定义，
   也不恢复旧七项菜单 / 旧训练岛。
