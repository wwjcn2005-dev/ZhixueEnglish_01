## 1. 审计结论

### 1.1 句子—官方音频对齐资产：**找回，而且是三套**

**去重后共 38 条唯一句子带可靠首尾时间**（40 条记录，2 条重复），涉及 13 个官方音频（AU01/AU03/AU04/AU06/AU11/AU13/AU14/AU19/AU20/AU26/AU28/AU41/AU46/AU47），**全部音频可解析到真实官方 MP3**（已用 `audio.resolve_official_audio()` 逐条验证）。

- **可直接复用**：上述 38 条（`sentence_text + audio + start_ms + end_ms`）已足够支撑"短句跟读 / 听音阅读时间轴"。
- **必须注意**：同一条句子存在**两套时间**（contentpack VERIFIED 与 P3-07 最终），差异 200–320ms（见 §3.2）；另外 P3-07 的 `selected_candidates_reviewed.json` 曾把 4 条判为不确定（3 条 `REAL_UNCERTAIN` + 1 条 `NEXT_SENTENCE_INTRUSION`），后来 `final` 全部改成 `BOUNDARY_PASS/HIGH`。因此**产品必须指定唯一权威来源**，不能两个都用。

### 1.2 本课检测：**题目有，答案与解析没有**

- 正式项目有 **360 条教材题目关系记录**（`structured/exercises/exercise_question_relations_v3.json`），带单元 / 板块 / 教材页 / 题型 / 关联教材文本(315) / 关联词汇(303) / 关联音频(121)。
- **但 `answer_source` 360/360 = `NO_RELIABLE_SOURCE`，没有正确答案、没有解析**；`contentpack.sub_question` 只有 13 条题干原文，也没有答案。
- 目前**唯一带正确答案 + 解释**的题目是 Demo 自己的确定性题库：`web/demo_content.py`（每单元 2 道短语/句型题 + 2 道阅读题，含 `answer` 与 `why`）。
- 结论：**"本课检测"目前只能以 Demo 确定性题库 + 听辨题库为骨架落地**；教材 360 条题目可以作为"教材依据 / 待补答案"的输入，但不能立刻当可判分题库。

### 1.3 AI 解释目前需要补什么

| 能力 | 当前是否可确定性完成 | 是否适合 AI |
| --- | --- | --- |
| 判断对错 | 只有 Demo 题库 + 听辨题库可确定性判分（教材 360 题无答案 → 不可以） | 不适合（应由规则做） |
| 给出正确答案 | Demo 题库可以；教材题**没有答案可给** | 不适合 |
| 判断知识点 | 可以（关联词汇/文本已有；题型已有） | 不适合 |
| 解释为什么错 | 不可以（只有 Demo 题库的 `why`） | **适合** |
| 语法解释 | 不可以（**项目没有语法数据表**，无语法点/规则） | **适合**（但教材依据只能引用句子） |
| 词汇解释 | 可以（教材词表 288 词释义可查） | 可选（AI 只做补充） |
| 教材例句 | 可以（`demo_content.EXAMPLES` + 教材原句 + `content_block`） | 不适合 |
| 新例句 | 不可以 | **适合** |
| 错题再次练习 | 可以（Demo 题库 + 听辨题库可重做） | 不适合 |
| 本课薄弱点总结 | 可以（基于 Cookie 记录做确定性归纳） | 可选（措辞可交给 AI） |

### 1.4 错题闭环缺什么

- 有：Demo Cookie 里已记 `answers`（练习选了哪个字母）、听辨作答、词汇判断、口语次数；练习结果页会列出错题；正式 Web Demo 另有 Cookie 错题池（`zx_wrong`）与 `/unit/<slug>/result`。
- 有：正式学习层表结构完整（`learning_record` / `mastery_state` / `task_item` / `learning_task` / `learning_session`）＋只读服务（`mastery_service`、`diagnosis_service`、`intervention_service`、`resource_pool_service`）。
- **缺**：① 错题的"错误原因分类"（无数据）；② 错题的教材依据链接（现在只知道 qid）；③ "再做一次"的独立重做状态与错题入口；④ AI 解释结果的固化落点（`contentpack.ai_artifact` 表存在但 **0 行**）；⑤ 正式 learning.db 数据极薄（21 条学习记录、7 条掌握状态，且 `mastery_level` 多为 `unknown`）——**Demo 的错题闭环现在只靠 Cookie，没有落库**。

### 1.5 AI 学习总结缺什么

- 能支撑：单词掌握（Cookie 词汇判断）、听音辨意表现（单词/句子正确数）、练习表现（每题对错）、口语（完成次数 + 确定性评价）、阅读完成。
- **缺**：① 短句跟读（Demo 还没有这个页面，因此没有数据）；② 本课检测（还没有独立页面，练习数据可复用但要重命名+补齐解释）；③ 错题的"知识点/教材依据"字段；④ 落库（现在全在浏览器 Cookie，换浏览器即归零）。

### 1.6 一句话结论

**句子的时间轴资产在（38 条，跨 7 单元，可直接复用）；题目在但答案和解析不在；错题有记录但无闭环（无原因、无依据、无重做、无固化落点）；AI 解释需要的"语法数据"完全不存在，只能靠教材句子+词表支撑。**

- **后续是否适合由 AI 做"句子精选"**：适合（选"有交际价值/有句型价值"的句子属于语言判断），但**必须在教材候选句范围内选**，且 AI 只能给候选，时间轴仍须来自 ASR/HUMAN 复核。
- **对齐应如何使用 start_ms/end_ms**：以官方 MP3 为唯一音源，`start_ms/end_ms` 只作为**播放区间**（不切文件、不生成新音频）；同一句只能有一套权威时间。

