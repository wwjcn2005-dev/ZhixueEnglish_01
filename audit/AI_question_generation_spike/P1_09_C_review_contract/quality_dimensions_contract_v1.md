# Quality Dimensions Contract V1

状态：**设计冻结建议稿（DESIGN ONLY）**。本轮不实现、不调用 AI、不新增 Prompt 规则。

这不是提示词，是**判定契约**：它规定每个维度"判断什么、谁来判、什么算 PASS/CONCERN/FAIL、
以及最容易误判的地方"。提示词将来只是这份契约的一种表达形式。

统一取值：`PASS` / `CONCERN` / `FAIL` / `NOT_APPLICABLE`（仅在第 5 维允许）。

---

## 1. english_correct — 英语正确性

| 项 | 内容 |
| --- | --- |
| 判断对象 | 题干、选项、答案的语法、拼写、搭配、标点、大小写 |
| AI 能判断 | 语法是否成立；搭配是否自然；选项内部是否有语法不一致 |
| AI 不能判断 | 教材是否"故意这样写"；教材原句本身的取舍 |
| PASS | 三个部分都语法正确、搭配正常 |
| CONCERN | 语法成立但搭配别扭、或与教材语体不一致 |
| FAIL | 存在明确语法/拼写错误，或答案与题干在语法上不相容 |
| 典型误判风险 | 把"简单"当成"错误"；把风格差异（英式/美式）当成错误 |

## 2. answer_unique — 答案唯一性

| 项 | 内容 |
| --- | --- |
| 判断对象 | 给定答案在声明标准（`TEXTBOOK_ANCHORED` / `SELF_CONTAINED`）下是否唯一 |
| AI 能判断 | 是否存在其他语法成立、语义成立、且不与教材语境冲突的候选 |
| AI 不能判断 | 程序的教材证据边界；也不能用一个标准去否定另一个标准下的结论 |
| PASS | 按声明标准，所有其他候选都被排除（`UNIQUE`） |
| CONCERN | 存在候选但明显不如给定答案自然（弱风险） |
| FAIL | 存在同样自然的第二候选（`UNIQUE_RISK`） |
| NOT_APPLICABLE | 不适用（本维不允许；判断题按课文事实走） |
| 典型误判风险 | ①因为答案出现在教材里就判 PASS；②用现实常识判 FAIL；③把"题目缺上下文"当成现实常识问题 |
| 附加字段 | `standalone_risk`（fill / vocab_choice 必填）、`alternative_answer`（判 FAIL 时必须写出） |

判定程序见 `answer_uniqueness_contract_v1.md`。

## 3. naturalness — 自然度

| 项 | 内容 |
| --- | --- |
| 判断对象 | 题干与选项是否像真实英语教材/真实英语使用者会写的样子 |
| AI 能判断 | 表达是否生硬、是否像机器拼接、选项长度/形式是否整齐 |
| AI 不能判断 | 教材编排意图、教学法偏好 |
| PASS | 读起来像教材原句或自然的练习题 |
| CONCERN | 可以接受但明显生硬 / 与教材语体不符 |
| FAIL | 不像真实英语（例如机械拼接、指代混乱到读不通） |
| 典型误判风险 | 把"教材原句本身很简单"当成不自然；把个人风格偏好当标准 |

## 4. learning_value — 学习价值

| 项 | 内容 |
| --- | --- |
| 判断对象 | 这道题是否真的训练了一个明确的学习点，而不只是机械操作 |
| AI 能判断 | 是否能说出"这道题在练什么"；是否只是把教材原句挖掉一个词且没有增量 |
| AI 不能判断 | 孩子的具体薄弱点；也不能替程序判定"是否属于教材重点" |
| PASS | 题目明确训练一个有价值的学习点，且不是单纯的教材原句机械挖空 |
| CONCERN | 有一定学习价值，但学习点偏弱，或练习形式过于机械 |
| FAIL | 基本只是复制/机械操作，没有独立学习价值 |
| 硬规则 | **机械形式 ≠ 自动 FAIL**。教材重点词的高质量语境填空，即使形式简单，仍可判 PASS |
| 典型误判风险 | 把"简单"当"没价值"；把"机械形式"直接判 FAIL（P1-09-B 已证明模型会正确区分这两者） |
| 已知弱点 | P1-09-B 中该维度检出率仅 1/2，最不可靠 → 使用前必须先用带明确标签的样本再验一次 |

## 5. distractor_quality — 干扰项质量（仅选择题）

| 项 | 内容 |
| --- | --- |
| 判断对象 | 干扰项本身的质量（**不是**答案唯一性） |
| AI 能判断 | 干扰项是否荒谬、是否与题干无关、是否与教材学习点无关、迷惑性是否合理 |
| AI 不能判断 | 教材编排意图；也不能要求"所有干扰项都必须来自教材词汇" |
| PASS | 干扰项合理、与教材学习内容相关、有迷惑性但可排除 |
| CONCERN | 干扰项勉强合理，但存在过于明显、或与学习点无关的选项 |
| FAIL | 干扰项明显荒谬 / 与题干无关 / 无法排除 |
| NOT_APPLICABLE | fill、reading_judge 等没有选项的题型 **必须**用此值 |
| 六类细分（必须区分） | ①语法不成立 ②语义明显不成立 ③与题干无关 ④虽然合理但存在第二正确答案 ⑤与教材学习点无关 ⑥合理且可排除 |
| 归属规则 | **④ 属于 `answer_unique`，不属于本维度**；①②③⑤⑥ 才属于干扰项质量 |
| 典型误判风险 | 把"干扰项太难"当"质量高"；把"干扰项是教材词汇"当硬要求（P1-09-A 已证明干扰项多为 BOLD 核心词） |

**明确不作为质量标准的两种想法**

```text
✗ 越难越好
✗ 所有干扰项都必须是教材词汇
```

## 6. grade_fit — 年级适配

| 项 | 内容 |
| --- | --- |
| 判断对象 | 词汇、句式、推理要求是否符合外研版初一（七年级上册，第一学期） |
| AI 能判断 | 是否出现明显超出当前阶段的词汇/句式；推理要求是否超纲 |
| AI 不能判断 | 具体班级进度；不做泛化的教育心理学判断 |
| PASS | 词汇与句式在教材合理范围内，题目仍适合初一学生完成 |
| CONCERN | 个别词/句式略超当前阶段，但可理解 |
| FAIL | 明显超纲到影响作答 |
| 典型误判风险 | 把"初一"理解成"越简单越好"（低年级简单题不等于不合格，超纲才是问题） |

## 7. 附加字段（不属于六维，但必须输出）

| 字段 | 取值 | 说明 |
| --- | --- | --- |
| `mechanical_level` | `DIRECT_REPRODUCTION` / `MECHANICAL_REWRITE` / `RECOMBINED` / `NOT_APPLICABLE` | **质量观察**，不是硬事实（见 §8） |
| `evidence_concern` | true / false | 题干或答案与所给教材证据明显不一致时的标记；不得据此推翻程序结论 |
| `context_insufficient` | true / false | 上下文不足时置 true，此时其余维度应输出 `CONTEXT_INSUFFICIENT` 而不是 FAIL |
| `suggested_decision` | `SUGGEST_ACCEPT` / `SUGGEST_REVIEW` / `SUGGEST_REJECT` | **建议**，不改变任何生命周期字段 |
| `short_reason` | 中文短句 | 10–40 字，面向不会英语的家长 |
| `confidence` | `HIGH` / `MEDIUM` / `LOW` | LOW 用于上下文不足或依赖教材编排意图的情况 |

## 8. 机械复现的职责重新确认（程序 = hard fact，AI = quality observation）

```text
程序（hard fact）        ：mechanical_rewrite / original_textbook —— 由 P1-07 闸门与
                            validator 依据"题干与教材原文的关系"确定性计算
AI（quality observation）：mechanical_level —— 从教学质量角度观察这道题的复现程度
```

规则：

```text
1. AI 不得推翻程序的教材结构判断，程序结果就是 hard fact
2. 两者不一致时不自动覆盖任何一方，而是把"存在分歧"写进人工复核信息
3. AI 的 mechanical_level 不得写回 question_library.db
```

**P1-09-B 已实测到 1 例定义差异**（`AIQ:120FFEECA78F`：程序 `mechanical_rewrite=False`，
AI 判 `DIRECT_REPRODUCTION`），原因是两者定义不同（前者看"题干是否为教材句的逐字片段再挖空"，
后者看"这道题本质上是不是把教材句挖了个空"）。**这是设计上预期的差异，不是缺陷，
也不需要把两个字段对齐。**

## 9. 维度之间的分工（防止再次混为一谈）

```text
english_correct     看"对不对"（语言）
answer_unique       看"是不是只有一个答案"（多解）
naturalness         看"像不像真实英语"
learning_value      看"练没练到东西"
distractor_quality  看"错误选项本身质量"（不含多解）
grade_fit           看"是否适合当前阶段"
```

最容易混淆的两处已经写进规则：

```text
"虽然合理但存在第二正确答案" → answer_unique（不是 distractor_quality）
"机械挖空但练的是教材重点词" → learning_value 可判 PASS（不是自动 FAIL）
```
