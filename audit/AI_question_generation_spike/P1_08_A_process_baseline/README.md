其中两条硬性要求直接来自实测教训：

1. **生成前必须建立完整教材证据**——不得用 `activity → page → text` 反推正文，
   "页面没有 activity"不能意味着该页正文被丢弃（依据：P1-07 发现 Unit 1 UI 课文主体页被漏）；
2. **截断即停**——`finish_reason=length` 不得解析、不得入库、不得继续下一个 Section
   （依据：P1-05-B 连续 6 次截断）。

## 已验证 vs 尚未验证（规范 §16）

- **已验证 17 项**：Section 级生成、无固定题量、可生成 0 题、DeepSeek 链路、
  16384 预算（5 个 Section 实测 `stop`）、截断即停、证据真实性、词汇边界口径、
  deterministic dedupe key、独立题库、PENDING_REVIEW、ACTIVE 硬门槛、单事务入库、
  provenance、人工审核前不进入学习、正式资产保护等。
- **未验证 14 项**：大规模批量稳定性、低证据 Section 行为、listening / grammar / writing /
  speaking 题型、规模化干扰项质量、长文本 Section、长期成本吞吐、教材版本 stale 实跑、
  schema v3 判断题取值、**证据组装层缺陷**、**APPROVED → ACTIVE 全流程未实跑**、
  learning_record 迁移、以及 §5.3 的边界裁决。

## V1.3 / V2.0 同步检查

```text
V2.0  全文未涉及 AI 题库/出题流程            → 无需修改
V1.3  有涉及（题库×6 / 生成题×3 / 无限题库×1） → 绝大多数条款与本规范一致
      其中 1 处需项目裁决（见下）              → 本轮不修改 V1.3，附建议文本
```

**该边界已于 2026-09-17 裁决：采用解读 A**

> "AI 可以生成教材训练题，但 AI 生成的题干、选项、答案不得冒充教材事实，
> 不得写入教材数据；AI 题独立存放，经审核后才能进入学习流程。"

生效口径：AI 题只存在于独立题库、绝不写入教材数据、必须经确定性校验与人工审核、
孩子端不得呈现题库概念、不允许随机大量生成。
解读 A 下与 V1.3 不存在实质矛盾 → **V1.3 / V2.0 本轮均不修改**；
规范 §5.3 保留一份**可选**的措辞澄清文本，供下一次 V1.3 修订时纳入（非阻塞）。
