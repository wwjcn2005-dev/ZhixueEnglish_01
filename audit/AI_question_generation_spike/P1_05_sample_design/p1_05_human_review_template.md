# P1-05-B · AI 题目人工审核表（模板）

使用方法：**按 Section 分组**审核。先读该 Section 的教材原文，再逐题填表。
每题只做 6 个 PASS / FAIL 判断，最后给一个归类。

---

> ## 审核员不应看到的信息（后台技术信息，禁止出现在本表中）
>
> `model` · `prompt_version` · `context_hash` · `generation_run_id` ·
> `validator_version` · `evidence_block_id` · `question_fingerprint` ·
> `lifecycle_status` · 任何数据库内部 ID
>
> 审核员**可以**看到：题目、选项、答案、解析、教材原文与引用、以及
> 「教材第 XX 页」这样的自然语言来源。

## 需要单独标注的情况（如出现，请在备注中写明并上报）

| 情况 | 说明 |
| --- | --- |
| 答案其实不唯一 | 教材证据无法排除另一个同样合理的答案 |
| 教材已直接印出答案 | 题目的正确答案同时出现在教材原题打印的选项里（"看到就选"风险） |
| 教材外事实 | 题目或干扰项使用了教材中没有的人物 / 事件 / 知识 |
| 同一处反复出题 | 多道题只是同一空位换问法，失去独立价值 |
| 与历史题重复 | 与 P1-03 等历史批次已入库的题实质重复 |

这些情况**不改变**上面的 6 项判断与最终归类，但必须在备注中记录，
以便汇总到 P1-05-B 的机制风险清单。
