## 三个必须一起读的结论

1. **P1-09-D 的 0/2 不是候选池覆盖问题，而是 AI 的总判定问题**：那两道题都是选择题，
   `students` / `word` 本来就在选项里，候选集合当时已经完整。
2. **填空题的候选池是数据问题，不是 Prompt 问题**：精确过滤会漏、宽过滤不可用、
   87% 的正文词没有词性、两个真实答案都不在教材词表里（也不是屈折或同义关系）。
3. **状态设计必须承认"找不到 ≠ 唯一"**：只有 `candidate_coverage = COMPLETE` 才允许
   `UNIQUE_SUPPORTED`；按实测，填空题在当前数据下**不应输出** `UNIQUE_SUPPORTED`。
