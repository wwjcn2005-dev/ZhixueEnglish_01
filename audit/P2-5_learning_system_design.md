## 一、结论摘要（先给判断）

1. **核心学习单位是 LearningObject（教材学习对象），不是 Activity，也不是 Exercise。**
   Activity 是任务容器，Exercise 是产生证据的手段，两者都不能代表“学会了什么”。
2. **“学过”= 接触证据（study），只陈述事实；“掌握较稳定”= 多重、跨时间、跨任务类型的证据集合。**
   单次做对、单次看视频、单次自评都不构成掌握。
3. **AI 最有价值的介入点是“开放作答的教材范围内批改与错误归因”，以及“教材范围内低频变式练习”。**
   AI 不决定学习路线，不生成教材外内容，不做评分排名。
4. **巩固不是“错题再做一题”，而是“问题类型 → 最合适干预”，并且默认教材优先、AI 兜底。**
   粗心/偶发错误**不干预**。
5. **专项学习应该存在，但只能是辅助入口（方案 B）**，且必须以教材范围为组织单位，不能是一级独立题库。
6. **阶段验证需要，但它解决的是“保持与迁移”，不是“考试与排名”**；它必须是可选、低频、无分数、结果只进证据层。
7. **完整闭环在原设想基础上必须插入两个环节：证据聚合（阈值）与孩子决定。**
   否则系统会滑向“AI 自动带学”或“错一次=薄弱”。
8. **现有架构判断**：教材/音频/练习数据层与学习事实层（record）**KEEP**；mastery/pool/session **EXTEND**；
   **掌握判定算法、诊断-巩固链路、AI 批改链路 REBUILD**；专项题库、阶段测试页面、家长系统 **DEFER**。

## 二、从孩子角度重建学习过程（场景 A：第一次学一个 Unit）

（完整时间线见 `structured/learning/learning_flow_v1.json` 的 `unit_first_run`，此处给出教育解读）

真实初一学生的第一个 Unit 学习，**不是**“刷完 22 个活动”，而是四段理解递进：

1. **进入话题（Starting out）**：图片 + 简单活动，建立“这个单元讲什么”的预期；
   这一步孩子最容易跳过，所以 APP 必须让它**便宜**（1–2 分钟）。
2. **理解文本（Understanding ideas）**：先听课文音频（🎧）再读课文，再做活动 3（选择主旨在教材上有选项）、活动 4（填空，教材给空线）、活动 5–6（语法圈词）。
   这是本单元最需要“回看教材”的一段，APP 的价值是**把音频、文本、题目放在同一屏上下文里**，而不是让孩子来回翻页。
3. **听与用（Developing ideas）**：听力活动 1–4 + 语法/语音小栏。听力必须用**教材官方音频**，题目保留教材原有结构（表格/海报/填空线）。
4. **输出（Reading for writing → Presenting ideas → Reflection）**：范例文本 → 写作任务 → 展示步骤 → 自评。
   输出类任务的反馈只能基于**教材范例与本单元语言**，不能变成通用英语作文批改。

孩子在整个过程中**做出全部关键决定**：先看还是先做、做几题、听几遍、要不要回看、是否继续。系统只做三件事：呈现真实教材、记录事实、在孩子提交后给出教材范围内的分析与建议。

## 三、“学习”到底是什么：状态模型

（见 `structured/learning/learning_model_v1.json`）

推荐的**最小且教育上站得住**的状态集合：

| 状态 | 含义 | 需要什么证据 | 是否是能力判断 |
| --- | --- | --- | --- |
| 未接触 | 无记录 | — | 否 |
| **学过** | 主动完成过一次教材学习动作 | ≥1 条 study 记录 | **否（只陈述事实）** |
| 练过 | 做过教材练习且有可判断结果 | ≥1 条 practice（correct/partial/incorrect） | 否 |
| 看起来会了 | 有中等强度证据支持“会做” | ≥2 次表现 + 至少 1 次无提示 | 是（置信度上限 medium） |
| **掌握较稳定** | 多次、跨时间、跨任务类型稳定正确 | ≥3 条判断证据 + ≥2 种任务类型 + 跨 ≥2 个自然日 + 最近 3 次 ≥2 次正确 + 无未处理的当前错误 | 是（置信度上限 high） |

**合并与删除的判断**：

- “接触 / 理解 / 回忆 / 识别 / 应用 / 稳定掌握”六个状态中，**接触与理解合并**（都只是接触证据，无法自动区分）；
- **识别与应用不单独作为状态**，而作为**证据类型**参与判定（选择=识别，填空/写作=应用）；
- **“掌握”不设百分比、不设等级**，只有 `stable` 这一个布尔式判定；
- **删除了“已掌握”这一常被误用的产品概念**：它既不可靠也不必要。

## 四、学习对象：教材内容如何成为 LearningObject

| 教材内容 | 是否成为 LearningObject | 组织方式 | 证据来源 |
| --- | --- | --- | --- |
| Vocabulary | 是 | 一个词条 = 一个对象（含 unit/词表位置） | 回忆、看中文写单词、教材词汇题 |
| Phrase | 是 | 一个固定搭配 = 一个对象 | 教材短语题、写作中的使用 |
| Sentence pattern | 是 | 一个句型 = 一个对象 | 教材句型替换/改写题、写作 |
| Grammar | 是 | 一个语法点 = 一个对象（挂教材指针页） | 教材语法活动、写作中的形式准确性 |
| Reading | 是 | 一篇课文 = 一个对象（含文本块） | 阅读理解题、定位题、朗读/复述 |
| Listening | 是 | 一个听力任务 = 一个对象（挂官方音频） | 教材听力题 |
| Speaking | 是 | 一个口语任务 = 一个对象 | 教材口语任务（自述/转写 + AI 反馈） |
| Writing | 是 | 一个写作任务 = 一个对象 | 教材写作任务（AI 对照教材范例） |
| Textbook exercise | **否（是证据来源）** | 挂在 LearningObject 上 | 产生证据 |

**关键区分**：

- `Activity ≠ Knowledge Point`：一个 Activity 可能测多个对象（如“Listen and complete the poster”同时考听力与词汇形式）；
- `Exercise ≠ Mastery`：题目只是证据产生器；
- `Correct Answer ≠ Mastery`：一次正确可能来自猜测或短期记忆。

## 五、Learning Evidence：什么证据能证明什么

（见 `structured/learning/learning_evidence_model_v1.json`）

| 证据 | 强度 | 能证明 | 不能证明 |
| --- | --- | --- | --- |
| 看过 / 听过 | 弱 | 接触过 | 理解、记得 |
| 自我评价（完成/再看一遍） | 弱 | 孩子主观判断 | 正确性 |
| 回忆（记得 / 有点模糊 / 忘了） | 中强 | 无提示下能否回忆 | 新语境中的应用 |
| 选择（A/B/C/D） | 中 | 在选项中识别 | 自主产出（有猜测概率） |
| 填空（教材保留空线） | 中强 | 语境中产出目标形式 | 长期保持 |
| 匹配 / 排序 | 中 | 建立教材内对应关系 | 表达 |
| 阅读理解（简答/信息匹配） | 强 | 真实文本中定位与推理 | 形式准确性 |
| 听力（官方音频） | 强 | 真实语流中获取信息 | 自主表达 |
| 口语 / 写作 | 强 | 整合教材语言输出 | 其他能力 |
| AI 批改结论 | 中 | 与教材事实的符合度（附理由） | 能力上限 |
| 多次跨日表现 | 强 | 保持与稳定 | 迁移到新任务 |

**组合规则（必须满足才升级）**：弱证据**永远不能单独**推动任何能力判断；`stable` 必须由“条数 + 任务类型 + 自然日”三者共同支持；同一会话内对同一对象的重复作答**只算 1 条**；AI 结论必须与孩子原始作答一起保存以便复核。

## 六、AI 批改：输出什么、什么时候不该下结论

（见 `structured/learning/ai_role_model_v1.json`）

AI 的**输出契约**（7 项，缺一不可）：
正确性（含依据）→ 错误类型（封闭集合：形/义/用/听/构/表达）→ 错误原因 → 是否教材范围内（附 Unit/Section/Activity/页码）→ 是否偶发（likely_slip / uncertain / repeat_error）→ 是否需要巩固（need_now / watch / no）→ 建议方式（取自干预模型，教材优先）。

**AI 必须不下结论的六种情况**：

1. 只有 1 次错误 → 不得判定薄弱，只能“注意观察”；
2. 开放式作答与“参考答案”不同 → 不得机械判错，要看是否符合教材事实；
3. 教材证据不足（题目信息缺失）→ 明确说明证据不足；
4. 听力题 → 以对应官方音频与教材听力文本为准，不凭常识推断；
5. 孩子中途退出/未作答 → 不产生负面判断；
6. 超出教材范围的内容 → 不评判、不讲解，标记 `out_of_textbook_scope`。

**成本形态**：选择/填空类走“本地规则判定 + AI 归因”，可缓存（同题同答）；开放类按需；解释类低频可缓存；变式生成低频、需触发条件；绝不做“每次打开页面调用 AI”或“批量生成题库”。

## 七、巩固：问题类型 → 干预方式

（见 `structured/learning/intervention_model_v1.json`）

| 问题类型 | 首选干预（教材优先） | 是否允许 AI 生成练习 |
| --- | --- | --- |
| P1 词汇形义不牢 | 教材词表 + 该词在课文中的原句回忆 | 允许（条件：教材已看过 + 同一错误 ≥2 次） |
| P2 语音/听辨 | 重听官方音频（🎧）+ 教材听力题重做 | 不允许（AI 只提示易混音） |
| P3 理解偏差 | 回教材原文（P2-4 `related_text` 指到段落）重读 + 定位关键句 | 不允许（AI 只做提问引导） |
| P4 语法结构 | 教材语法指针页（Know more about … pNN）+ 教材例句 | 允许（条件：教材例句已看 + 同类错误出现在 ≥2 个任务） |
| P5 听力细节 | 重听 + 对照教材题目结构定位信息点 | 不允许 |
| P6 表达类 | 对照教材范例（Reading for writing）找结构 | 不允许（AI 只按教材要求给反馈） |
| P7 粗心/偶发 | **不干预**（只记录） | 不允许 |
| P8 综合/迁移不足 | 教材跨板块混合练习 | 允许（条件：教材混合练习已完成 + 孩子主动要求） |

**一句话规则**：能用教材原文/音频/原题解决的，绝不用 AI 生成；AI 生成只在“教材确实没有对应练习”且“错误已重复出现”时兜底。

## 八、专项学习：三个方案的比较与推荐

| 维度 | 方案 A：教材学习 + 独立专项并列 | 方案 B：教材为主，专项为辅助入口 | 方案 C：无独立专项，全部由需要驱动 |
| --- | --- | --- | --- |
| 教育效果 | 容易把注意力从课文理解挪到刷知识点 | **好**：专项只服务教材薄弱点 | 好但**路径隐蔽** |
| 孩子自主性 | 高（但选择困难，易被题量吸引） | **高**：需要时可见、可进 | 中：孩子不知道去哪找 |
| 认知负担 | 高（两套主线） | **低**（一条主线 + 一个辅助入口） | 低但方向感差 |
| 产品复杂度 | 高（独立的题库、进度、统计） | **中** | 低 |
| 教材主线完整性 | 弱（两条主线竞争） | **强** | 强 |

**推荐：方案 B。**
理由：教育上专项确实有价值（词汇/语法需要集中重复），但它必须以**教材范围**为单位（Unit/Section 内），且入口只在“有证据触发”或“孩子主动”时出现；一级导航不设独立题库。方案 A 会导致产品退化为题库（与最高原则冲突），方案 C 让孩子在需要集中练习时找不到入口。

**实施边界**：专项的题目来源只能是教材原题 + 教材范围内变式；专项不得引入教材之外的知识点；专项入口的标题必须标明所属教材范围（例如“Unit 1 · 词汇需要再学”）。

## 九、阶段验证（原“阶段混合测试”）的准确角色

（见 `structured/learning/stage_assessment_model_v1.json`）

**它解决三个教育问题**：保持（隔时间还会不会）、迁移（换任务类型还会不会）、综合（跨板块/跨单元是否稳）。

**设计要点**：

- 触发：Unit 学完后**孩子可选**；或连续 2–3 个 Unit 后可选；
- 禁止：刚做过同一题就测；把它当作进入下一单元的门槛；频繁执行；
- 题源优先级：教材原题（不同活动）→ 教材原题的换题型使用 → 教材范围内 AI 变式（最低优先并显式标注）；
- 题量：5–8 题、5–10 分钟；
- **无分数、无正确率、无排名、无等级**；孩子只看到“还能做出来 / 这次没做出来 + 回教材页码入口”；
- 结果**不直接改写掌握状态**，只作为证据进入诊断；
- 中途退出不产生负面结论。

## 十、推荐的完整学习闭环

```
教材（主线，P2-4 结构）
   ↓
孩子选择要学的内容
   ↓
学习（看/听/读教材原文与官方音频）—— 主动确认「我学完了」
   ↓
教材练习（真实题型：选择/填空/匹配/排序/判断/简答/写作）
   ↓
AI 批改（基于教材证据包：正确性 / 错误类型 / 原因 / 是否教材内 / 是否偶发 / 是否需巩固 / 建议）
   ↓
证据（写入事实层，不立即下结论）
   ↓
★ 证据聚合（阈值）  ← 原设想缺少的环节
   ↓
诊断（只在满足阈值时给出“疑似”，附证据条数）
   ↓
★ 孩子决定（继续 / 回教材 / 重听音频 / 做一次针对性练习 / 跳过）  ← 原设想缺少的环节
   ↓
干预 / 巩固（教材优先，见干预模型）
   ↓
再次验证（换任务类型，或延迟到下次）
   ↓
证据累积 → 稳定掌握判定
   ↓
继续教材
   ↓
阶段验证（可选：保持 + 迁移 + 综合）
   ↓
综合诊断（跨单元，指向可回教材的位置）
   ↓
回到教材或进入下一个 Unit
```

与原设想的差别（4 处，均有教育理由）：
1. 插入**证据聚合（阈值）**——否则单条证据直接诊断，会出现“错一次=薄弱”；
2. 把**孩子决定**显式化为闭环步骤——否则 AI 建议会变成事实上的指令；
3. 阶段验证从“必经关卡”改为**可选分支**；
4. “再次验证”要求**换任务类型或延迟**——立刻重做原题只证明短期记忆。

## 十一、孩子与 AI 的职责边界

| 事项 | 谁决定 | 说明 |
| --- | --- | --- |
| 学哪个 Unit/Section、何时学、学多久 | **孩子** | 系统不排序、不推荐下一步 |
| 是否听音频、听几遍、是否回看教材 | **孩子** | 音频不自动播放 |
| 做哪几道教材题、是否跳过 | **孩子** | 不强制完成任务 |
| 是否接受巩固建议 | **孩子** | 系统只建议入口 |
| 是否做阶段验证 | **孩子** | 可选、不设门槛 |
| 记录学习事实、聚合证据、批改请求 | **系统自动** | 不影响孩子的节奏 |
| 批改结论、错误归因、巩固建议、教材定位 | **AI** | 必须带依据；不替孩子决定 |
| 提醒（例如“上次有内容需要再看看”） | 系统**可建议不可强制** | 孩子学习进行中不弹窗、不自动跳转 |

**不打扰原则**：学习过程中不弹窗、不自动跳转、不自动播放；只在孩子回到首页/单元页时以静态信息呈现“需要再学”的内容。

## 十二、从学习逻辑反推的产品结构（下一阶段参考）

导航服从学习过程，建议维持“一条主线 + 三个辅助面”：

1. **教材（主线）**：教材中心 → Unit → Section → 教材内容与活动 → 学习/练习/AI 批改/结果。
2. **需要再学（辅助，证据驱动）**：当前错误 / 疑似薄弱（附教材页码），入口来自证据而不是自动推荐。
3. **专项（辅助，教材范围内）**：只在有需要或被孩子主动打开时出现，标题带教材范围。
4. **阶段验证（辅助，可选）**：Unit 完成后可选，结果指向教材位置。

不增加的：题库、排行榜、积分、打卡、家长看板、AI 自动学习计划。

## 十三、现有实现对照：KEEP / EXTEND / REBUILD / DEFER

（详细技术影响见 `audit/P2-5_architecture_impact.md`）

### KEEP
- **LearningRecord 事实层**（`learning_record`：行为 + 结果 + attempt_no + hints_used + response_raw + 时间）——正是本设计需要的“证据原始事实”。
- **只读资源池**（`resource_pool_service`：当前错误=最近 judged=incorrect，当前薄弱=最近 judged=partial）——作为“当前状态事实”可用，**前提是文案不得表述为薄弱点结论**。
- **孩子主动确认的交互**（Study「我看完了」、Recall「记得/有点模糊/忘了」）——与“孩子做主 + 主动证据”一致。
- **教材/音频/练习数据层**（P2-3 音频证据链、P2-4 结构/视觉/上下文/证据包）。
- **判分边界**：`skipped / NULL / done` 不计入正确证据（P1-06-C2-A 规则）。

### EXTEND
- **mastery_state**：保留 `mastery_level/evidence_count/correct_count`，但**判定输入必须扩展**为“任务类型 + 自然日 + 证据强度 + 是否无提示”，否则不足以支撑 `stable`。
- **资源池**：增加“未处理 / 已处理”和“错误次数（≥2 才算疑似）”两个维度，把“当前错误”与“疑似薄弱”在语义上分开。
- **Session/Task**：需要区分“教材主线会话”与“巩固会话”“阶段验证会话”（现有 `entry_point` 可扩展，不必重构表）。
- **Web 练习结果页**：从“自评 + 记录”扩展为“显示 AI 批改结论占位（本阶段仍离线）”。

### REBUILD
- **掌握判定算法**：现状是 `mastery_level` 声明了 `unknown/learning/familiar/stable` 四档，但代码只累加计数、**从不推进等级**（真实数据里 3 条证据仍是 `unknown`）。这不是“算法不好”，而是**算法不存在**；必须按 §三 的证据集合重新设计（不要用计数器升级）。
- **诊断 → 巩固链路**：当前完全缺失（`/review` 只是只读池展示）。
- **AI 批改链路**：当前只有 `web/ai_grading.py` 的本地规则预检（无教材证据包、无输出契约）。

### DEFER
- 专项独立题库与进度统计、阶段验证的产品化页面、家长/教师视图、任何 gamification。

## 十四、必须明确 REJECT 的既有设想

| 编号 | 被拒设想 | 理由 |
| --- | --- | --- |
| REJECT-1 | “看过 = 学过 = 会了” | 接触不构成能力证据 |
| REJECT-2 | “做对一次 = 掌握” | 可能来自短期记忆或猜测 |
| REJECT-3 | “错一次 = 薄弱点” | 单次错误多为偶发；必须阈值+归因 |
| REJECT-4 | 用 evidence_count 自动升级等级 | 缺少任务类型/时间/强度维度 |
| REJECT-5 | 专项学习作为一级并列主线（方案 A） | 会把产品拉向题库化 |
| REJECT-6 | 阶段测试给分数/排名/等级 | 与“孩子做主、教材为主”冲突 |
| REJECT-7 | AI 自动决定学习路径或自动布置任务 | 剥夺孩子决定权 |
| REJECT-8 | 巩固 = 错题无限再练 | 退化为刷题，且脱离教材 |
| REJECT-9 | AI 生成教材之外的内容/知识点 | 破坏教材事实源 |

## 十五、14 个核心问题的直接回答

1. **一个 Unit 的最佳基本流程**：Starting out（话题）→ Understanding ideas（听课文音频 + 读课文 + 教材题）→ Developing ideas（教材听力 + 语法/语音）→ Reading for writing（范例 + 写作）→ Presenting ideas/Reflection（输出与自评）；每步孩子可选、可跳、可回看。
2. **APP 的核心学习单位**：LearningObject（教材学习对象：词/短语/句型/语法点/听力任务/阅读文本/写作任务）；Activity 与 Exercise 是任务与证据产生器。
3. **什么叫“学过”**：有 ≥1 条主动学习行为记录（study）；系统只陈述事实，不声称理解。
4. **什么叫“掌握较稳定”**：≥3 条判断证据 + ≥2 种任务类型 + 跨 ≥2 个自然日 + 最近 3 次 ≥2 次正确 + 无未处理当前错误。
5. **什么证据支持判断**：回忆/填空/阅读/听力/口语/写作 + 多次跨日表现（强中弱三档，弱证据不可单独升级）。
6. **AI 最有价值的介入点**：开放作答的教材范围内批改与错误归因；以及在明确条件下生成教材范围内的少量变式练习。
7. **AI 不应该做**：决定学什么/何时学；自动推进；生成教材外内容；把教材题替换为自造题；给分数排名；证据不足时给确定结论。
8. **巩固怎么做**：按 P1–P8 问题类型选择干预，教材优先（原文/音频/语法指针页/范例/原题），AI 只在教材无对应练习且错误重复时生成变式；粗心错误不干预。
9. **专项学习是否存在**：存在，但为**辅助入口（方案 B）**，以教材范围为组织单位，由证据触发或孩子主动进入。
10. **阶段验证是否需要**：需要；它解决“保持、迁移、综合”三个问题，是可选的、无分数的、结果只进证据层的检查。
11. **孩子与 AI 的边界**：孩子决定学习内容/时间/节奏/是否巩固/是否验证；系统自动记录与聚合；AI 批改与分析；系统可建议但不强制，学习过程中不打扰。
12. **最终闭环**：见 §十（含证据聚合与孩子决定两个新增环节）。
13. **架构保留与推倒**：KEEP=record 事实层、只读池现状语义、孩子主动确认交互、教材数据层；EXTEND=mastery 输入、池语义分层、会话类型、结果页；REBUILD=掌握判定算法、诊断-巩固链路、AI 批改链路；DEFER=专项题库、阶段测试页面、家长系统。
14. **下一阶段应该开发什么**：①证据模型落地（任务类型/日期间隔/强度）；②教材证据包接线 + 离线 AI 批改契约原型（不接真实 API）；③最小诊断-巩固闭环（教材优先）；④阶段验证数据结构；⑤之后才谈 UI。

## 十六、已可确定 vs 需要真实孩子验证

**已可确定（教育逻辑与数据支撑都成立）**

- 学习对象与证据的分层（对象 ≠ 任务 ≠ 题目 ≠ 答案）；
- 单次事件不构成掌握、不构成薄弱；
- 教材优先的干预顺序，AI 只在限定条件下生成练习；
- 阶段验证的定位（保持/迁移/综合、无分数、可选）；
- 专项学习的层级（辅助入口、教材范围）；
- 现有 mastery 等级未推进、诊断-巩固链路缺失、AI 批改未接入这三个 REBUILD 判断。

**必须通过真实孩子使用才能确定（本阶段不猜）**

- 5–8 题的阶段验证是否有负担、间隔 1 天/3 天/一周哪种更能区分保持；
- `stable` 的具体阈值（3 条/2 类/2 天是否偏松或偏紧）；
- 孩子是否愿意主动做巩固与阶段验证；提示频率多少才不打扰；
- AI 批改输出中“错误类型”的分类粒度是否对初一学生可理解（形/义/用/听/构/表达）；
- 首页“需要再学”与专项入口的呈现方式是否真的降低了翻找成本（可用真实使用时长与回访率验证）。
