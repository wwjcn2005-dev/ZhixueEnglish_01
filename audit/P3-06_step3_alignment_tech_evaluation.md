## 3. 六个必答问题

**Q1｜需要 Speech-to-Text 还是 Forced Alignment？**
**本质上需要 Forced Alignment（B）**：课文文本已经准确存在，问题只是"定位"，让 ASR 重新识别一遍等于把已知事实再猜一次。但**现实中**可落地的免费本地工具里，真正成熟的强制对齐器（MFA/gentle）在 Windows 上部署成本高，因此**工程上推荐 C（用 Whisper 产词级时间，再用已知文本做确定性匹配）**——它是 B 的近似实现。

**Q2｜Whisper 类方案是否值得采用？**
**值得**，但定位必须清楚：**只把它当作"时间来源"，绝不把它当"教材文字来源"**。识别文本一律丢弃/仅作匹配用，教材句子永远以 content_block 为准。

**Q3｜faster-whisper 与 whisper.cpp 哪个更适合本机？**
**推荐 faster-whisper**：Python 生态、直接给 word-level timestamps、支持 int8（CPU）与 float16（GPU）、可完全装在 D 盘 venv（含 `nvidia-*` CUDA 轮子，无需系统 CUDA Toolkit）。whisper.cpp 也可行（单 exe + GGML 模型、CPU 即可跑），但需要单独获取二进制且 Windows 上 word timestamps 的后处理更繁琐。

**Q4｜GTX 1070（实测 8GB）能否承担？**
**能**：`small`/`medium` int8 或 float16 都在显存内；即便只用 CPU（16 线程 int8）也可跑，只是慢 2–5 倍。驱动 560.94 已足够新。

**Q5｜自动生成的时间是否需要人工校验？**
**需要**：判定为「**自动产生候选时间 + 人工快速校验**」。依据：① SAPI 前车之鉴说明"有数字 ≠ 位置对"；② 专有名词与短句易出现边界偏差；③ 校验成本很低（整段 43s 听一遍即可核对 4–8 句）。
