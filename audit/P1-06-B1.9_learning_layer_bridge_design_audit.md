## 6. Goal → Task（问题 C）

**推荐**：Task 必须引用 `goal_id`（回答“为什么学”），并同时引用具体资源（回答“学什么”）。

```text
LearningTask(task_id, learner_scope, goal_id, task_kind, prompt_template_version, ...)
TaskItem(task_id, item_id, item_role)
```

理由：goal 无法表达“这一条词/短语/句型”；只有 goal 会导致任务无法定位内容，只有 resource 会导致任务失去学习意图。

## 7. Resource → Task（问题 D）

**核心结论：Resource ≠ Task。**

| 资源类型 | 可能产生的任务（示例） |
| --- | --- |
| Vocabulary | 认读 / 理解词义 / 拼写 / 发音 / 语境判断 / 句中使用 / 复习 |
| Phrase | 理解 / 搭配识别 / 语境使用 / 在 Sentence Pattern 中应用 / 复习 |
| Sentence Pattern | 识别骨架 / 替换 slot / 理解功能 / 模仿表达 / 自由迁移 / 复习 |

**推荐方案**：Task 通过 `TaskItem` **直接引用 `item_id`**（多对多），并冗余保存 `goal_id` 便于聚合与统计。理由：一条资源产生多个任务、一个任务覆盖多条资源；仅通过 goal 间接引用会丢失精确性，无法支撑掌握度与复习调度。

## 8. Resource → Record（问题 E）

**推荐**：学习记录只描述“孩子做过什么”，通过 `task_id` + `item_id` + `learner_id` 引用，**绝不写回教材资源**。

```text
LearningRecord(record_id, learner_id, task_id, item_id, started_at, finished_at,
               result, response_raw, hints_used, duration_ms, attempt_no)
```

边界示例：孩子答错一次 → 只新增一条 record；`Vocabulary.canonical_text`、`Phrase.meaning_zh`、`SentencePattern.pattern_template` **均不得被修改**。

## 9. Resource → Mastery（问题 F）

**推荐**：掌握状态属于用户学习层，主键为 `(learner_id, item_id)`；同一教材资源对不同孩子有不同 masterystate，**资源本身保持用户无关**。

```text
MasteryState(learner_id, item_id, mastery_level, evidence_count, last_practiced_at,
             next_review_at, stability, note)
ReviewItem(learner_id, item_id, due_at, reason, source_record_id)
```

## 10. Resource → AI Artifact（问题 G）

**推荐**：AI Artifact 通过现有 `ai_artifact` 的通用目标字段引用教材资源，**单向依赖**（AI 依赖资源；资源不依赖 AI）。

```text
AIArtifact(artifact_id, artifact_kind, target_layer, target_id, context_ref_ids,
           content_markdown, model, prompt_version, confidence, review_status, is_visible_to_child)
  target_layer='textbook_resource' → target_id=<item_id>
  context_ref_ids → 额外教材证据（如 source_ref_id / content_block_id）
```

约束建议（设计层，不实施）：`artifact_kind ∈ {explanation, example, exercise, diagnosis, hint}`；默认 `is_visible_to_child=false`，经审核（`review_status`）后才可见；`context_ref_ids` 必须保留教材来源以便追溯。

## 11. Vocabulary 桥接

**资源现状**：287 条（`textbook_emphasis` = BOLD 616 / PLAIN 92，来源级；`learning_requirement` = CORE 243 / RECOGNITION 43 / NEED_REVIEW 1（peaceful）；`review_status` = OK 196 / NEED_REVIEW 91）。

边界结论：

```text
BOLD / PLAIN      = 教材排版事实（来源级证据）
CORE              = 教材要求“掌握并会用”（学习要求语义）
RECOGNITION       = 教材要求“认识、能读懂”
NEED_REVIEW       = 数据治理状态（不等于错误、不等于低优先）

因此：BOLD ≠ 学习任务；CORE ≠ “今天必须学”。
```

桥接路径：`Vocabulary(item)` →（派生学习目标）→ 任务序列（认读 / 词义 / 拼写 / 发音 / 语境判断 / 使用 / 复习）→ 记录 → 掌握状态。NEED_REVIEW 条目可以进入学习层，但任务生成时应标注证据状态供人工参考。

## 12. Phrase 桥接

**资源现状**：23 条（21 条词表多词条目 + 2 条语言注释固定语言单位）；`:P:` 命名空间；`learning_requirement` = RECOGNITION 21 / CORE 2；`review_status` = NEED_REVIEW 23。

边界结论：**Phrase 不是 Vocabulary 的子类**，学习层**不得**把它写成“多词 Vocabulary”。Phrase 与 Vocabulary 可以共享同一 `content_block`（21 组同文本，合法），但 item_id / content_hash / 学习要求全部独立。

任务序列建议：理解 → 搭配识别 → 语境使用 → 在 Sentence Pattern 中应用 → 复习。

## 13. Sentence Pattern 桥接

**资源现状**：52 条；`:SP:` 命名空间；`canonical_text = pattern_template`（教材骨架 + `{n}` 槽位）；`textbook_emphasis` = UNKNOWN 52；`learning_requirement` = CORE 1 / NEED_REVIEW 51；`requirement_conflict_status` = OK 52。

边界结论：**Pattern 是结构资源，不是完整句**。`I like {1}` 的资源身份**不等于** `I like apples.`；完整句只能来自 example / exercise / AI 产物，且不得反向生成 Pattern。

任务序列建议：识别骨架 → 替换 slot → 理解功能 → 模仿表达 → 自由迁移 → 复习。槽位是学习对象本体（当前只记位置 `{1}{2}`，无语义类型）。

