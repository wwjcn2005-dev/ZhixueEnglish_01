## 7. 「词汇表音频」与「课文听力音频」的区别（重要）

| 类型 | 说明 | 本册情况 |
|---|---|---|
| A. 独立词汇发音 | 单独的词汇发音音频（一个词一条或可精确定位到词） | **不存在**：只有 7 个「单元词汇表整体朗读」音频，无逐词独立音频、无切分标记 |
| B. 课文/对话中的自然出现 | 某词在该单元课文音频中被自然读到 | 存在，但**不能**据此认定该词拥有独立词汇发音；除非未来有可靠的切分/对齐证据 |

因此：287 条 Vocabulary 的官方音频覆盖只能标记为 **CANDIDATE（单元级词汇表音频）**，不得标记为 CONFIRMED。

## 8. v3 是否已有发音相关字段

```text
learning_item ：已有 phonetic（IPA 文本）、part_of_speech；无 audio / pronunciation_source / audio_source / voice_type / fallback_level
source_ref    ：无发音相关字段
content_block ：无发音相关字段
audio_asset   ：audio_id / textbook_id / snapshot_id / filename / relative_path / sha256 / size_bytes / duration_ms / bitrate / sample_rate / channels / id3_version
audio_mapping ：audio_id / target_type / target_id / mapping_status(CANDIDATE) / …

```

结论：**v3 已具备承载「音频资产 + 候选映射」的基础（audio_asset / audio_mapping），但发音来源分级（official / system TTS / AI）与 IPA 之外的信息尚无字段**——这与《发音资源与语音能力原则》中「本次仅写入设计规范、不得修改现有数据库」的要求一致。未来建议在 v4 设计时新增：`pronunciation_source / audio_source / audio_status / locale / voice_type / fallback_level`。
