## 3. 新增原则 A（六·8 教材文字—音频—上下文—Question 严谨锚定原则）

**写入位置**：第六章第 8 条（V1.2.1 新增）。

**核心内容（原文要点）**

- 锚定链：教材文本 → 上下文 → 官方音频 → 教材活动 → Question → 回答区域，必须形成**可验证、可追溯的确定性关系**，每条关系都要能指出教材依据并保留审核状态。
- 只有存在教材事实或确定性结构证据时才允许建立映射；**正式教材事实优先于程序推断**。
- 下列因素只能作候选线索，**不得单独用于推断关系**：页面相邻；文件相邻；活动编号相近；音频时长；文字长度；文件名相似；AI 语义判断；“看起来应该对应”；同页存在的其他内容。
- **同一页存在多个活动时，不得仅按页码**把题目、正文、对话或音频串到一起。
- Question 必须锚定到明确的教材活动与上下文；无法确定时**不返回题目**、标记 NEEDS_REVIEW，不得串题。
- 听力材料与 Question 必须锚定；一段音频可服务同一活动的多道题，但**每道题不得跨活动**。
- **正文、Dialogue、Reading 不得因为解析方便而被当作 Question 题干。**
- 锚定关系只能是只读派生，不得反向修改教材事实。

## 4. 新增音频边界（六·9 官方音频完整性与切分原则）

**写入位置**：第六章第 9 条（V1.2.1 新增）。

1. 出版社已按活动提供独立官方音频时，默认使用**官方完整音频**。
2. 不得因为“文字短、音频长”认为音频错误。
3. 不得根据文字长度推测音频播放范围。
4. 不得根据音频时长推测题目边界。
5. 不得使用 AI 猜测音频切点。
6. 不得为了 UI 方便制造未经验证的音频片段。
7. 只有存在教材结构提供的明确、可验证边界时，才允许建立片段级映射。
8. 无法确定边界时：保留官方完整音频 + 完整教材文本/上下文 + 标记 NEEDS_REVIEW + 禁止自动猜测。
9. 结论口径：**准确锚定优先于切割；官方完整音频优先于未经验证的切割**；**本规范不要求把听力切成短句或短片段**。
10. 音频播放行为本身不产生正式判断证据。
11. 现状事实：54 条音频 = 41 活动级 + 13 板块级，无跨活动音频，SPLIT_REQUIRED = 0。

## 5. 新增原则 B（七·7 正式教材练习批改责任原则）

**写入位置**：第七章第 7 条（V1.2.1 新增）。

- 正式教材练习必须经过系统/规则/AI 的正式批改或分析后，才能形成正式学习证据。
- 链路：孩子选择练习 → 孩子作答 → 系统/规则/AI 批改 → 结果 → 错误与薄弱分析 → Evidence → Mastery / Diagnosis。
- **孩子的自主权（不变）**：学什么、哪个单元、哪项内容、什么时候学、学多久、是否暂停、是否继续、是否复习、是否进行阶段验证。
- **系统/AI 的专业职责**：批改；判断正确/错误/部分正确；错误分析；教材证据解释；Evidence 形成；Mastery 计算；Diagnosis；后续建议。
- 必须明确：**孩子拥有学习选择权，但不承担系统应该完成的专业批改责任。**
- 禁止：把“请你自己判断做得怎么样”作为正式教材练习的核心闭环；把“我完成了这次练习”作为正式正确/错误证据。
- 没有可靠答案事实时，系统**暂不判分并说明原因**（NEEDS_REVIEW），不等于把判断推回给孩子。

配套新增：

- **七·8 客观题与主观题的批改边界**：客观题（choice / judge / fill_blank / match）有可靠答案时用确定性规则判分，无答案时不判分并标记 NEEDS_REVIEW；禁止 AI 猜答案、常识替代、语言模型生成答案、上下文推测写入正式答案。主观题（short_answer / writing / speaking 开放任务）可用 AI 做语义分析、教材证据对照、评分判断、错误分析与建议，但必须受教材事实、上下文、题目要求、评分标准约束，AI 不能创造教材事实。
- **七·10 自我判断与完成动作的证据边界**：“我完成了 / 我觉得会了 / 我觉得做对了 / 我觉得做得不错 / 我自己判断掌握了”均不能产生 correct / incorrect / partial，也不能产生正式 Evidence；`done` 尤其不能作为正式正确/错误证据；完成动作只能表示“发生过一次学习或作答行为”。正式 Evidence 只能来自可验证的规则判分、可靠答案事实、AI 批改结果或明确的正式判断结果。

## 6. 答案事实原则（七·9）

**写入位置**：第七章第 9 条（V1.2.1 新增）。

- **教材答案是独立于教材内容事实的另一类事实。**
- 教材内容事实：正文、对话、阅读、词汇、句型、活动、音频。
- 教材答案事实：choice 正确选项、judge 判断结果、fill_blank 答案、match 对应关系、其他需要标准答案的客观题。
- 即使教材内容事实完整，**也不能推导出可靠教材答案**。
- 没有可靠答案来源时：**禁止自动补答案**，状态进入 NEEDS_REVIEW，等待教师用书、官方答案或人工核验的可靠来源。
- 实测基线（P2-6-F-0）：157 练习 / 360 题，可靠答案 0；教材学生用书无答案页、项目无教师用书 → 人工核验答案前**客观题不判分**。

## 7. NEEDS_REVIEW 原则（十一·8）

**写入位置**：第十一章第 8 条（V1.2.1 新增）。

- 无法由教材事实确定的内容一律进入 NEEDS_REVIEW：题目结构；题目与上下文关系；音频与文本关系；音频片段边界；选择题选项；填空位置；教材答案；主观题评分标准；其他不确定教材事实。
- 含义：**禁止自动修复**；等待可靠事实来源或人工核验。
- 不是“AI 帮忙猜一下”，也不是“先补上再核验”。
- 只存在于开发数据与报告中，不得进入孩子界面。
- 解除的唯一途径：可靠事实来源（教师用书、官方答案、人工核验结论）+ 记录审核人与依据。

## 9. 未修改的核心原则（V1.2 原有正确内容全部保留）

- 教材是主线，AI 是辅助；APP 负责整理与提效，而不是替代教材

- 专项学习的位置（教材主线下的辅助入口，不是独立题库主线）
- 不自动推进、不自动选科、不自动规划学习路径、不游戏化、不做排行榜/积分/等级
- AI 数据复用优先原则、AI 成本控制、AI 与教材数据隔离、AI 反馈水平与阶段适配
