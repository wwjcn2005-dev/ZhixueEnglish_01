## 7. Fixed sentence pattern 分析

全册检索：`固定句型` 仅出现 **1 处**（PDF p.131 / 教材 p.126）。

```text
教材原文：it’s no secret that...是固定句型，意为“众所周知......,...... 不是秘密”，
          强调某事物是公开的，毫无疑问的。例如：
          It’s no secret that exercise is good for our health.
          It’s no secret that we live in a digital age.
正文实例：pdf94（Unit 6 课文） It’s no secret that Brits love afternoon tea.
```

判定：**FIXED_SENTENCE_PATTERN**（教材显式“固定句型” + 从句槽位 + 3 个实例）。

**为什么不能归 Phrase**：① 槽位是完整陈述从句（句级），不是词/短语级单位；② 教材在同一页把 `prefer A to B` 称为“搭配”、把 `it’s no secret that...` 称为“固定句型”，教材自身给出两级边界；③ 具备可迁移句式与多实例。

## 16. 规则总结

- R1 必须有教材明确教学证据（教材措辞 / Communication bank / Useful expressions / Guide 标题）
- R2 句级骨架（含 S+V 或系表结构）才可能成为 Sentence Pattern
- R3 必须存在显式可替换槽位（“...” / 括号 / 斜杠可替换项）
- R4 教材使用“固定句型”措辞 → FIXED_SENTENCE_PATTERN
- R5 教材以语法规则讲授（时态/句型标题/句式变化）→ GRAMMAR_ONLY，不升级
- R6 词汇/短语级单位 → PHRASE_ONLY；正文普通句 → ORDINARY_SENTENCE
- R7 证据存在但边界无法确定 → NEED_REVIEW，禁止自行升级
- R8 频率只作辅助证据，不得单独作为纳入依据（本阶段 0 条因高频而纳入）

证据等级（任务定义）：A = 教材明确标注固定句型/句式；B = Communication bank 稳定结构；C = 语言注释说明的句式结构；D = Grammar 中作为句式教学对象；E = 正文反复出现且可迁移（本阶段 0 条直接纳入，仅 NEED_REVIEW）。
