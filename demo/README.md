# 智学英语全功能交互 Demo（课时化版）

一个**完全独立**的电脑浏览器 Demo：打开首页，就能像真实初一学生一样走完一遍学习。
本轮的定位是「延续已经认可的正式 UI 风格 + 把全链路做顺 + 把未来 AI 的产品形态模拟出来」，
**不是重新设计**。

它不是正式 APP，也不是正式 Web：不写任何正式数据、不调用任何 AI、不安装任何依赖、不切割教材音频。
（唯一例外见「课文简答 → 学习证据」：课文简答会把**一条模拟 AI 评价**写进正式
`structured/learning/learning.db`，用来验证评价结果能否进入统一学习机制；真实 AI 调用仍然是 0。）

## 启动

```text
python -B D:\ZhixueEnglish\demo\server.py
```

浏览器打开 `http://127.0.0.1:8780/`（正式 Web 是 8770，两者互不影响）。

- 手机/平板同网络试：`python -B D:\ZhixueEnglish\demo\server.py --host 0.0.0.0`，
  访问 `http://<本机IPv4>:8780/`。注意：**局域网地址下浏览器不允许使用麦克风**（非安全上下文），
  口语页会明确提示，并且不录音也能继续看到 AI 演示分析。录音请在电脑上用 `127.0.0.1` 体验。
- 健康检查：`/health`；停止：`Ctrl+C`。

## 学习单位是"课时"，不是 Unit

```text
教材 → Unit → 课时（= 教材板块 Lesson）→ 当前课时真实拥有的资源 → 当前可用的学习功能
```

- 课时名直接来自教材（`section` 表）：`Get ready / Know your school / Get to know each other /
  Make a wishing tree / Starting out / Understanding ideas / Developing ideas / Reading for writing /
  Presenting ideas / Reflection`——不新造 Lesson 编号。
- 首页顶部只有「七年级英语上册」+ **一个当前课时选择器**（按 Unit 分组的 optgroup）。
- **能力按课时动态生成**：当前课时有什么资源就显示什么入口；没有的完全不显示，
  不出现"暂不可用 / 即将开放 / 暂无资源 / 灰色按钮"。
- **「自主练习」是第 7 个入口**：它不是某一种教材资源能力，任何课时都在，样式/交互与前 6 个入口
  完全一致（同一行 `.entryrow`）；状态只有"未开始 / 继续"（做过专项或巩固练习才算继续）。
- 状态（判断/作答/跟读/完成）以"课时"为作用域分别保存（Cookie），换课时互不影响。

## 学习链路

```text
首页（教材名 + 当前课时选择器 + 当前课时可练的入口）
 → Unit（当前课时 + 课时切换 + 这节课可以练什么）
   → ① 单词跟读（纯跟读：单词 / 音标 / 中文 → 听教材发音 → 麦克风跟读 → 我的朗读 → 左右滑动下一个）
   → ② 听音辨意（默认单词听辨，顶部可切句子听辨；听 → 选 → 立即反馈 → 下一题 → 统一结果）
   → ③ 本课检测（6 题/单元，全部有正确答案；答对给简洁反馈，**答错才出现 AI 解释**：
        为什么错 / 教材依据 / 教材例句 / 建议 + 再试一次 + 看看错题；AI 不提前公布答案）
   → ④ 短句跟读（教材短句 + 官方 MP3 的 start_ms–end_ms 区间 → 大麦克风录音 → 我的朗读 →
        AI 分析中 → AI 朗读分析：完整度 / 发音表现 / 流畅度 三条语义色进度条 + 具体发现 + 建议；
        **左右滑动切换句子**）
   → ⑤ 听音阅读（官方 MP3 + 教材文字；文字按 start_ms/end_ms **跟随播放**高亮，整段播完自动进入下一段，
       不提供上一段/下一段按钮）
   → ⑥ 课文简答（教材原句 → 孩子写一句 → 批改 / 分析 / 指导：用到的教材说法、还可以用上、
        掌握情况、教材依据、建议；想改就直接改输入框再交一次，想继续就用「看学习结果」）
   → ⑦ 自主练习（一段简短学习总结 + 专项练习 / 巩固练习；练什么由孩子自己选，没有证据就不出入口）
 → 学习结果（当前课时：单词 / 听音辨意 / 本课检测 / 短句跟读 / 听音阅读 + 需要再看 + 值得再看看 +
    本课错题 + 课文简答 + AI 学习分析，全部只针对当前课时）
 → 继续学习（回首页用顶部右侧的首页入口，不再放第二个首页入口）
```

导航规则：**页面内"返回"回上一层**，**首页是顶部右侧的独立入口**；
结果页只给"继续学习"，不强迫继续；**同一个首页入口只出现一次**（顶部右侧）。
连续学习内容（单词跟读、短句跟读）用**左右滑动**切换，不再有"上一项/下一项"按钮。
在某个页面里切换 Unit / 课时时，会**留在同一个页面**（不会跳回首页）。

旧入口兼容：`/unit/<slug>/speaking` → 短句跟读，
`/unit/<slug>/vocab/result` → 回到纯跟读页（记忆判断已删除）。
`/unit/<slug>/practice` 现在是**自主练习页**（原来只是"→ 本课检测"的旧入口兼容），
它的子路由 `/practice/special`、`/practice/reinforce`、`/practice/result` 保持原样。

## AI：完全虚拟，调用次数 0

- 口语：停止录音后先显示 `.analyzing`「AI 正在分析」（约 800ms），再显示
  **完整度 / 发音表现 / 流畅度 / 具体发现 / 建议**，全部是定性描述（不使用百分制伪精确分数）。
- 场景确定性生成（至少 4–6 种）：整体较好 / 某个教材词需要注意 / 停顿较多 / 内容不完整 /
  第二遍有所改善 / 整体稳定没有特别提醒。同样的输入永远得到同样的结果（sha256 决定）。
- "具体发现"必须落到本次教材内容：优先该单元核心词表里的词（例如句子里的 `school`、`life`）。
- 学习结果页的 **AI 学习分析** 按本次真实学习行为生成：词汇 / 听音辨意 / 练习 / 口语 + 一句话建议，
  措辞永远是"如果你愿意，可以……"；**不生成任务、不安排计划、不替孩子决定**。
- **课文简答**（教材句 → 孩子写一句）：规则层复用正式 `web/ai_grading.py` 的确定性预检
  （不联网、不调用 AI），语言层是确定性模拟（同样的句子永远得到同样结论）；
  只给"用到的教材说法 / 还可以用上 / 掌握情况 / 教材依据 / 建议"，用词沿用统一评价语言
  （基本掌握 / 掌握较稳定 / 需要巩固），**不出现伪精确分数**；
  孩子可以直接改输入框再交一次，也可以直接「看学习结果」，AI 不替孩子改句子。

#### 课文简答 → 学习证据（最小闭环 Spike）

```text
课文简答（教材句 / 教材问题）
  → 模拟 AI 评价（say_grading，确定性；AI_PROVIDER=None，不联网）
  → result 三值映射（carries 且 complete 且 coverage>=0.6 → correct；carries → partial；否则 incorrect）
  → LearningRecord（activity_type=produce，response_raw = 结构化评价 JSON）
  → evidence → mastery → 当前错误/薄弱池
```

- 实现：`demo/say_evidence.py`（Demo 侧最小衔接）；只复用 `learning/` 既有
  `session_service.create_learning_session` + `learning_service.record_learning_event`，
  **不直接 INSERT、不改 schema、不改 mastery / resource pool 规则**。
- **教材 item 必须真实**：课文简答的句子必须是在 contentpack 登记过的教材句子
  （`audio_sentence_annotation`），再由它的 activity 文本 + PDF 页定位到**唯一**教材 activity，
  该 activity 经 `source_ref(source_type='activity')` 关联的 learning_item 也必须**唯一**；
  任一步不成立 → 这次不写记录（不伪造 item）。当前 20 个可简答课时里只有
  Unit 1 · Developing ideas 满足该映射。
- 评价结果按现有三值 `correct / partial / incorrect` 写入；结构化评价（content / language /
  textbook_basis / guidance / source / ai_called）整体放在 `response_raw`，
  `ai_called=false` 明确标记这是模拟。

## 听音阅读与音频

- **PDF 点读路线已取消**：Demo 里没有教材原页图片、没有坐标定位/热点，`/page/*.jpg` 已返回 404。

- 句子听辨里，Unit 1 使用已人工核验的句子区间（数据本来就有），其它单元用整段活动原声并在页面上如实标注。

## 已知边界（诚实说明）

1. **口语没有真实 ASR**：只说"完成了几次跟读"，评价是确定性虚拟数据并明确标注。
2. **非 Unit 1 的句子素材是整段原声**：只有 Unit 1 有 12 条人工核验的句子级时间；其它单元用自然段首句 +
   该段完整原声，页面已如实标注"这一段是整段录音"。
3. **一个阅读段 ↔ 一段完整活动音频**（明确不切割）：一段里可能包含教材多页的正文，
   也可能听到比屏幕上的文字略多一点（例如活动指令）。
4. **学习时长是环节完成累加**（单词 6 / 听辨 4 / 阅读 4 / 练习 4 / 口语 3 分钟），不是真实计时。
5. **教材文本块里保留了教材自身的活动编号**（例如 `1 . It is...`），因为不改动教材文本。
6. **手机浏览器不能录音**（非安全上下文），只能看演示分析。
7. **听音阅读没有逐句同步**：不做句级高亮/字幕，段落内是多句连读的整段原声。
8. **句级时间轴只有 38 条**：Unit 3、Unit 5 各只有 1 句，其它单元 2–4 句；短句跟读页面里的
   "第 n / N 句"就是这个单元已对齐的数量，不做任何伪造补齐。
9. **本课检测的教材依据来自教材词表与教材原句**（不是语法体系）：项目当前没有语法数据表，
   所以 AI 解释里的"语法"说明只能引用教材句子本身。
10. **错题与学习状态只存在浏览器 Cookie**（`zx_demo10`），不写 learning.db；换浏览器即重新开始。
    （课文简答是唯一例外：它额外写一条正式 LearningRecord，用于验证评价 → 证据链。）

## 本轮纠偏补充（课时化 + 跟读交互）

11. **课时覆盖不均**：Demo 只在 `Understanding ideas / Developing ideas / Reading for writing`
    （Starter 为 `Get ready / Know your school / Get to know each other / Make a wishing tree`）
    有资源；`Starting out / Presenting ideas / Reflection` 没有材料，因此**不进入课时选择器**
    （不显示占位、不显示灰色按钮）。
12. **本课检测题量随课时变化**（1–4 题）：题目由本课时的教材重点词与本课时教材句子生成，
    没有材料就不显示"本课检测"。
13. **单词跟读是纯跟读**：没有记忆判断、没有正误评价、没有掌握度、没有 AI 判断；
    连续内容用左右滑动切换，底部只有「听发音 / 麦克风 / 我的朗读」。
14. **听音阅读没有翻页按钮**：靠 start_ms/end_ms 驱动文字跟随，整段播完自动进入下一段。
15. **课时映射口径**：句子按"教材页 → 板块"归属（P3-07 的 20 条通过 matched_candidates 的 pdf_page 回连），
    单词按词条印刷页归属，听音阅读按自然块的教材页归属；音频板块名只作为回退信号。

## AI 随堂助教与专项 / 巩固练习（本轮产品级调整）

**数据链**：

```text
孩子实际学习 → 学习证据（本课检测答错 / 听音辨意选错 / 短句跟读记录）
   → AI 随堂助教分析 → 具体发现 → 本课重点 → AI 建议
   → 专项练习（针对 1 个具体问题）
   → 巩固练习（当前课时 + 当前课时之前**真实学过**的课时）
   → 孩子自己决定是否开始
```

- **AI 随堂助教内容全部来自真实证据**：`demo/server.py::lesson_evidence()` 只读取 Cookie 里
  真实发生过的作答/跟读记录；每条发现都带**来源**（本课检测 / 听音辨意 · 单词听辨 / 短句跟读）与
  **证据强度**（答错 / 选错 / 第 n 次跟读）。**没有证据就不编结论**——页面只如实说明"这节课还没有学习记录"。
- **结构**：`[AI图标] AI 随堂助教` → **本课发现**（≤3 条，带来源）→ **本课重点**（具体词/用法）→
  **AI 建议**（一句话，具体到词）→ 有依据时给出 **专项练习 / 巩固练习** 入口。
  排版紧凑（标题 margin ≤10px、列表行距 1.55、AI 卡 padding 14px/16px），不是大卡片堆叠。
- **专项练习**：只针对第一条具体发现（例如某个词的意思/用法），题目来自教材词表与原题（1–3 题）。
- **巩固练习**：把**当前课时**的发现与**当前课时之前真实学过**的课时发现组合成 3–5 题；
  **不使用未来课时**（按教材全局顺序取 `studied_before()`，且只取真的有学习记录的课时）。
- **孩子做主**：两个入口都只在有证据时出现（没有就不显示，也不显示"暂无"）；按钮写"专项练习 / 巩固练习"，
  没有"必须完成 / 下一步 / AI 安排 / 今日任务"；点进去才做，做完即结束。
- **底部返回首页已删除**：AI 随堂助教页底部只保留一个操作（回到学习结果），并**水平居中**；
  顶部仍保留标准的返回上一层 + 首页入口。

新增路由：`/unit/<slug>/practice/special?p=<证据id>`、`/unit/<slug>/practice/reinforce`、
`POST /unit/<slug>/practice/answer`、`/unit/<slug>/practice/result?s=<session>`。

**「自主练习」页（`/unit/<slug>/practice`，首页第 7 个入口）**：同一份真实证据，只压成
**一段简短学习总结**（发现处数 + 本课重点 + 一句建议），下面直接给 **专项练习 / 巩固练习** 两个入口
（复用同一个 `.ai-pt` 组件与同一套 session 逻辑），不再堆「本课发现 / 本课重点 / AI 建议」三个模块。
练习链接带 `&b=own`：从自主练习进去的，做完回**自主练习**；从 AI 随堂助教进去的（没有该参数，
原链路）做完照旧回 **AI 随堂助教**。「AI 随堂助教」页本身保持原样，入口与既有功能不变。
